# Introduction

KubeVirt provides CRDs (Custom Resource Definitions) such as **VirtualMachine** and **VirtualMachineInstance** to abstract virtual machine (VM) resources. Based on these CRDs, users gain comprehensive VM management capabilities. Building on this foundation, **Alauda Virtualization** further enhances usability by offering a **Web Console**, enabling users to perform various operations with greater ease.
