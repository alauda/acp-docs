# Prepare Registry

Prepare the external platform image registry before application teams build, push, pull, or deploy images that depend on it.

| Need | Continue with |
| --- | --- |
| Prepare the registry used by the platform and upload the required payload. | [Prepare an External Platform Image Registry](../../install/prepare/external-platform-image-registry.mdx) |
| Use images from workloads or developer workflows. | [Images](../../developer/images/overview.mdx) and [registry image use](../../developer/registry/index.mdx) |

Complete the external registry preparation before teams depend on the platform image registry. A `global` cluster upgraded from an earlier version can continue to use the platform built-in Registry; use the registry administration pages for that upgraded-cluster case.
