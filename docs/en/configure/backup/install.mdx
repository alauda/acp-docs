# Install

Follow these steps to install the component.

:::note
Starting in ACP 4.5, the following plugins are renamed:

- **Alauda Container Platform Data Backup for Velero** is named **Alauda Container Platform Data Backup**.
- **Alauda Container Platform Cluster Enhancer** is named **Alauda Container Platform Cluster Enhancement**.

Search for the new name when you download a plugin from the Customer Portal. A plugin package published before the rename still shows the former name in the platform after you upload it.
:::

## Download

:::info
To use backup and recovery, download the application named **Alauda Container Platform Data Backup** (previously **Alauda Container Platform Data Backup for Velero**) from the <Term name="company" /> Customer Portal.
To use etcd backup, download the application named **Alauda Container Platform Cluster Enhancement** (previously **Alauda Container Platform Cluster Enhancer**) from the <Term name="company" /> Customer Portal.
:::
