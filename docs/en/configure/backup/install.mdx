# Install

Follow these steps to install the component.

:::note
Starting in ACP 4.5, **Alauda Container Platform Data Backup for Velero** is named **Alauda Container Platform Data Backup**. Search for **Alauda Container Platform Data Backup** when you download the plugin from the Customer Portal. A plugin package published before the rename still shows **Alauda Container Platform Data Backup for Velero** in the platform after you upload it.
:::

## Download

:::info
To use backup and recovery, download the application named **Alauda Container Platform Data Backup** (previously **Alauda Container Platform Data Backup for Velero**) from the <Term name="company" /> Customer Portal.
:::
