# Machine Configuration

**Machine Configuration** provides centralized management of the underlying operating system, allowing the platform to define and distribute OS configurations (such as kernel parameters, system services, and network settings) in a declarative manner. This ensures consistent configuration and runtime environments across all nodes, reducing operational complexity.

Machine Configuration applies only to clusters whose nodes run Alauda OS. On these clusters, the node operating system is immutable, and configuration updates are applied through controlled images or configuration policies, ensuring repeatability and system stability. Machine Configuration is not supported on nodes that run a non-Alauda OS.

Machine Configuration is delivered with Alauda OS clusters. It does not require a separate installation and does not have a separate release cadence. Its changes are described in the <Term name="product" /> [Release Notes](../../overview/release_notes.mdx).
