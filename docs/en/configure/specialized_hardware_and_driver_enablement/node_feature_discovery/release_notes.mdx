# Node Feature Discovery release notes

## v0.20.1-alauda.5

Alauda delivers Node Feature Discovery v0.20.1-alauda.5 as the `nfd-operator` OLM
Operator Bundle.

### Highlights

- Replaces the earlier Cluster Plugin delivery with an OLM Operator.
- Supports Linux AMD64 and ARM64 packages.
- Manages NFD through the `NodeFeatureDiscovery` custom resource.
- Validated NFD discovery labels on GPU AMD64, Ascend NPU ARM64, and ACP 4.4
  environments.
- Validated Operator upgrade, operand tag update, uninstall/prune, and
  reinstall flows.
- Updated the `api/nfd` module's `golang.org/x/net` dependency to v0.62.0.

### Known notes

- NFD discovery labels are separate from GPU/NPU driver and device-plugin
  labels. Those products have their own compatibility and workload tests.
- If `spec.image.tag` is explicitly set on the CR, update it deliberately when
  changing the operand version.
- The OpenPGP dependency observation has no fixed version in the advisory and
  is tracked as a non-blocking security observation under the current release
  policy.
