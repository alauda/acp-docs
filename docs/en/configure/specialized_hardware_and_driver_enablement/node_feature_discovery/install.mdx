# Install Node Feature Discovery

This page describes the OLM installation path for the `nfd-operator` package.

## Prerequisites

- The target cluster runs a supported ACP version and architecture.
- The `nfd-operator` package is available in the ACP OperatorHub.
- Any older NFD Cluster Plugin is uninstalled before installing the Operator.

## Install the Operator

1. Go to **Administrator** > **Marketplace** > **OperatorHub**.
2. Switch to the target cluster.
3. Find and install **Alauda AI Infrastructure Node Feature Discovery**
   (`nfd-operator`). Keep the default installation namespace unless your
   platform policy requires another namespace.
4. Approve the InstallPlan when the Subscription uses manual approval.
5. Wait until the CSV reports **Succeeded**.

## Create the NodeFeatureDiscovery resource

Installing the Operator alone does not deploy the NFD operands. Create a
`NodeFeatureDiscovery` resource after the CSV is ready:

```yaml
apiVersion: aml.dev/v1alpha1
kind: NodeFeatureDiscovery
metadata:
  name: node-feature-discovery
  namespace: node-feature-discovery
spec:
  image:
    repository: build-harbor.alauda.cn/mlops/node-feature-discovery
    tag: v0.20.1
```

Use the image tag provided by the package or by the platform's image relocation
configuration. Do not copy the build registry value into an air-gapped cluster
unless that registry is reachable from the cluster.

## Verify the installation

```bash
kubectl -n node-feature-discovery get csv
kubectl -n node-feature-discovery get nodefeaturediscovery node-feature-discovery
kubectl -n node-feature-discovery get deployment,daemonset,pods
kubectl get nodes --show-labels
```

The CR should report `Deployed=True`. The operator, master, and garbage
collector Deployments and the worker DaemonSet should be ready. Selected nodes
should contain `feature.node.kubernetes.io/*` labels.
