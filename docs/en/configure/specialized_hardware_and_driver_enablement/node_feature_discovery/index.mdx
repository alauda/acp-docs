# Node Feature Discovery

Node Feature Discovery (NFD) discovers hardware and operating-system features
on Kubernetes nodes and publishes them as `feature.node.kubernetes.io/*`
labels. Accelerator plugins and workloads can use these labels for placement.

The current delivery is the `nfd-operator` OLM Operator Bundle. It replaces
the earlier Node Feature Discovery Cluster Plugin delivery.
