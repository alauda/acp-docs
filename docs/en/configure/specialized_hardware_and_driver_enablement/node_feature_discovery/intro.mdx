# Node Feature Discovery

NFD detects node hardware and system features and publishes them as Kubernetes
node labels. Its native labels use the `feature.node.kubernetes.io/` prefix;
the `nfd.node.kubernetes.io/feature-labels` annotation records the labels
published by the NFD worker.

NFD is a discovery component. GPU or NPU driver, device-plugin, allocator, and
workload behavior are managed by their respective products. Installing NFD
does not install or configure those components.

## Delivery

Starting with the Alauda `v0.20.1-1` release, Alauda delivers NFD as the `nfd-operator` OLM Operator
Bundle. The Operator manages a `NodeFeatureDiscovery` custom resource and the
NFD master, worker, and garbage collector workloads.

## Supported architectures

The community NFD v0.20.1 baseline is delivered by the Alauda `v0.20.1-1`
release, which provides Linux AMD64 and ARM64 packages. Select the
package architecture that matches the target cluster.
