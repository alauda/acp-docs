# Overview

<Term name="productShort" /> Registry documentation has two administration tracks. Use the
Operator-managed <Term name="productShort" /> Registry for current ACP 4.4 deployments. Use the
legacy Registry pages only for environments that still run the Registry Cluster Plugin.

Developers and application teams use the registry through developer image workflows.

For earlier ACP 4.4 Registry installations, contact technical support for the supported upgrade and
migration plan.

## Administration scope

| Need | Continue with |
| --- | --- |
| Administer the Operator-managed <Term name="productShort" /> Registry. | [Alauda Container Platform Registry](./registry_v2/index.mdx) |

## Namespace isolation and access

Registry image repositories are organized by namespace. Pull and push access depends on the platform roles and permissions granted to users or ServiceAccounts in the target namespace.

For common image usage commands and cross-namespace pull access, see [Registry image use](../../developer/registry/index.mdx).
