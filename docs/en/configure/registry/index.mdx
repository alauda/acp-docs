# <Term name="product" /> Registry Administration

Use this section to install, configure, expose, and administer <Term name="productShort" /> Registry
for ACP 4.4.

The Registry is deployed in `image-registry-system` and reconciled by
`cluster-image-registry-operator`. It uses `Config/cluster`, `ImagePruner/cluster`, the
`image.alauda.io/v1` Image API, and managed service account pull secrets.

For Registry versions earlier than `v4.4`, contact technical support for upgrade and migration
plans.
