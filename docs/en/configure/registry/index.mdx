# Alauda Container Platform Registry Administration

The Image Registry Operator manages Alauda Container Platform Registry. It runs in
`image-registry-system` and deploys Registry workloads in `cpaas-system` by default. Administrators
configure the Registry and scheduled pruning through the cluster-scoped `Config/cluster` and
`ImagePruner/cluster` resources.

> **Important:** For Alauda Container Platform Registry versions earlier than `v4.4`, contact
> technical support for upgrade and migration plans.

For developer access and workload image pulls, see
[Alauda Container Platform Registry image use](../../developer/registry/index.mdx).
