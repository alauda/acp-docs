# Alauda Container Platform Registry Administration

Use this section to install, configure, expose, and administer Alauda Container Platform Registry for
ACP 4.4.

The Image Registry Operator runs in `image-registry-system` and manages Registry workloads in
`cpaas-system` by default. The cluster-scoped `Config/cluster` and `ImagePruner/cluster` resources
control Registry configuration and scheduled pruning.

> **Important:** For Alauda Container Platform Registry versions earlier than `v4.4`, contact
> technical support for upgrade and migration plans.

Developer and workload tasks are documented in
[Alauda Container Platform Registry image use](../../developer/registry/index.mdx).
