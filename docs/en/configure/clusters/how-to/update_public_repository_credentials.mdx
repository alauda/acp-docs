# Updating Public Repository Credentials

## Overview

The `Public Repository` is a platform-provided image registry service available on the public internet. When you want your clusters to use the `Public Repository` as their image registry, you need to update the built-in `public-registry-credential` Cloud Credentials. This ensures your platform has permission to pull images from the public registry.

`public-registry-credential` is the platform's built-in registry credential, and its effect is not limited to clusters configured to use the `Public Repository`. On clusters provisioned through Immutable Infrastructure providers, a cluster that does not reference a registry credential of its own resolves its platform image source from this credential. Updating it therefore affects those clusters as well. Confirm which clusters depend on it before you change its contents.

<Directive type="info" title="Giving a cluster its own registry credential">
  A cluster can be bound to a registry credential of its own instead of inheriting this one, so that it pulls platform images from a registry closer to it. The binding is chosen when the cluster is created and cannot be changed afterwards. See <ExternalSiteLink name="immutable-infra" href="/how-to/workload-cluster-image-registry.html" children="Choose the Image Registry for a Workload Cluster" />.
</Directive>

## Procedure

1. Log in to the **<Term name="company" /> Customer Portal** and download your organization's authentication file from the **Enterprise Management** section located in the **User Information** dropdown in the upper right corner.

2. Navigate to **Clusters** > **Cloud Credential** in the left navigation bar of the **Administrator** console.

3. Locate the cloud credential named `public-registry-credential` and click **Update** from the dropdown menu on the right.

4. In the **Upload Public Repository Address** section, upload the authentication file you downloaded from the **<Term name="company" /> Customer Portal**.

5. Click **Update** to apply the changes.
