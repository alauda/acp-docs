# Manage Nodes on Alauda OS Clusters

This section covers day-2 node operations on clusters whose nodes run Alauda OS.

:::info
**Nodes of the `global` cluster**

Before you scale out or in, replace a control plane or worker node, or rely on a MachineHealthCheck on the `global` cluster itself, make sure the infrastructure provider for the platform that `global` runs on and the Cluster Bootstrap Provider are installed on `global` as cluster plugins. A `global` cluster installed with `ac` already runs both; otherwise see the provider installation page for [Bare Metal](../../../workload_clusters/alauda_os/bare-metal/prerequisites.mdx#providers), [Huawei DCS](../../../workload_clusters/alauda_os/huawei-dcs/prerequisites.mdx#providers), [Huawei Cloud Stack](../../../workload_clusters/alauda_os/huawei-cloud-stack/prerequisites.mdx#providers), or [VMware vSphere](../../../workload_clusters/alauda_os/vmware-vsphere/reference/install_provider.mdx). In a DR pair, do this on both `global` clusters.
:::
