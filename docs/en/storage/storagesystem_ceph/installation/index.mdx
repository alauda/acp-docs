# Install

Internal Mode can back OSDs in either of these ways:

- Host devices selected in the web console. See [Deploying in Internal Mode](./create_service_stand.mdx).
- Block PersistentVolumes from Local Storage. Provision volumes in [Local Storage Guides](../../local_storage/functions/index.mdx), then see [Deploying in Internal Mode with Local Storage](./create_service_stand_local_storage.mdx).

Do not mix the two OSD backends on the same `CephCluster`. External Mode consumes an existing Ceph service instead of creating one.

<Overview />

For clusters using Immutable Infrastructure, first read <ExternalSiteLink name="immutable-infra" href="/overview/index.html" children="About Immutable Infrastructure" />, then read [Prerequisites for Deploying on Immutable Infrastructure](./immutable_infrastructure_prerequisites.mdx) before installation.

To upgrade an existing **Alauda Build of Rook-Ceph** Operator, see [Upgrade](../upgrade.mdx).
