# Introduction

Local Storage statically provisions PersistentVolumes from disks and partitions that are already attached to cluster nodes. It is delivered by the **Alauda Build of LocalStorage** operator.

Use Local Storage when a workload must consume a specific local disk or partition through a standard PersistentVolumeClaim. The operator creates a StorageClass and one PersistentVolume per matched device. Workloads then bind those volumes through PersistentVolumeClaims.

Local Storage does not replicate data across nodes. If the node or disk fails, the volume is unavailable.

## Choose a storage system

The Storage Systems section documents three storage systems. Choose one based on how volumes are provisioned and whether data must survive a node failure.

| Storage system | Provisioning | Typical use | Data protection |
| --- | --- | --- | --- |
| **Local Storage** | Static. One PersistentVolume per listed disk or partition. | Expose a specific local disk to a workload, including as a Block volume consumed by another storage system. | None beyond the disk. Node or disk failure loses the volume. |
| **LVM Storage** | Dynamic. TopoLVM carves logical volumes from node volume groups. | Databases and caches that need low-latency local volumes and PVC resize. The Marketplace package name remains **Alauda Build of TopoLVM**. | None beyond the node. |
| **Ceph Distributed Storage** | Dynamic. Replicated or erasure-coded pools. | Shared block, file, and object storage that must survive a node failure. | Replicas or erasure coding across nodes. |

Do not use Local Storage and LVM Storage as interchangeable names. Local Storage is the static local-disk provisioner. LVM Storage is the TopoLVM-based dynamic provisioner.

## Device discovery does not create volumes

The operator can discover unused block devices and write the result to a `LocalVolumeDiscoveryResult` object for each node. Discovery is an inventory. It does not create PersistentVolumes, StorageClasses, or filesystems.

PersistentVolumes are created only after you apply a `LocalVolume` or `LocalVolumeSet` that selects devices. Those procedures are in [Guides](./functions/index.mdx).
