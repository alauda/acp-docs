# Remove volumes and uninstall

Delete provisioned local volumes before you uninstall **Alauda Build of LocalStorage**. Uninstalling the operator does not delete your `LocalVolume`, `LocalVolumeSet`, StorageClass, or PersistentVolume objects. Do not uninstall the operator as a way to wipe disks.

Provisioning and binding claims stay in [Guides](../functions/index.mdx).

## Delete a LocalVolume or LocalVolumeSet

The operator keeps a finalizer on `LocalVolume` and `LocalVolumeSet` until no owned PersistentVolumes remain. Bound volumes and volumes with a `Retain` reclaim policy block deletion.

**Prerequisites**

- You have installed **Alauda Build of LocalStorage**.
- You know the object name in `acp-storage`.

**Procedure**

1. List PersistentVolumes owned by the object:

   ```bash
   kubectl get pv -l storage.openshift.com/owner-name=<local-volume-name>
   ```

2. Delete every PersistentVolumeClaim that is bound to those volumes. Wait until the claims are gone.

3. Delete the object:

   ```bash
   kubectl -n acp-storage delete localvolume <local-volume-name>
   ```

   For a `LocalVolumeSet`:

   ```bash
   kubectl -n acp-storage delete localvolumeset <local-volume-set-name>
   ```

4. If the object stays in `Terminating`, list remaining owned PersistentVolumes again. Delete or change reclaim policy on volumes that still exist. Do not remove the finalizer until those volumes are gone.

   Available volumes with `Delete` reclaim policy are released by the operator and then removed. Volumes with `Retain` reclaim policy are not removed automatically; delete them only after you no longer need the data.

:::warning
Deleting a `LocalVolume` or `LocalVolumeSet` can destroy data on the underlying disks when PersistentVolumes use the `Delete` reclaim policy. Confirm no workload still needs those volumes.
:::

## Uninstall Alauda Build of LocalStorage

Uninstall the operator only after you have deleted the `LocalVolume` and `LocalVolumeSet` objects you no longer need, or after you have decided to leave those objects in place.

The platform-created `LocalVolumeDiscovery` named `auto-discover-devices` may be removed when the operator subscription is deleted. Your `LocalVolume` and `LocalVolumeSet` objects are not deleted by uninstall.

**Procedure**

1. Login, go to the **Administrator** page.

2. Click **Marketplace** > **OperatorHub**.

3. Find **Alauda Build of LocalStorage** and open the installed operator.

4. Uninstall the operator. Do not select options that delete operands or custom resources if the console offers them.

5. Confirm the operator pods in `acp-storage` are gone:

   ```bash
   kubectl -n acp-storage get csv | grep local-storage
   ```
