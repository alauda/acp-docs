# Guides

After you install **Alauda Build of LocalStorage**, use these guides to inventory disks and to provision PersistentVolumes.

Device discovery lists unused block devices. It does not create PersistentVolumes, StorageClasses, or filesystems. PersistentVolumes are created only when you apply a `LocalVolume` or `LocalVolumeSet`.
