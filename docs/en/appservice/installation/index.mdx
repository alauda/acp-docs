# Install

Install Alauda Application Services in the following order:

1. Install the Operator of each product you will use, and the plugins that the web console needs. See [Install Plugins and Operators](./plugins_and_operators.mdx). For CloudNativePG, Valkey, ClickHouse, OpenSearch, and Milvus, follow the installation guide in the documentation of each product: <ExternalSiteLink name="cnpg" children="CloudNativePG" />, <ExternalSiteLink name="valkey" children="Valkey" />, <ExternalSiteLink name="clickhouse" children="ClickHouse" />, <ExternalSiteLink name="opensearch" children="OpenSearch" />, and <ExternalSiteLink name="milvus" children="Milvus" />.
2. Choose the storage for the instances and backups of each product. See [Storage Selection](./storage_selection.mdx). If you consider an enterprise SAN, also check it against the [requirements](./validate_storage.mdx#requirements) and run the [disk performance test](./validate_storage.mdx#disk) at this point.
3. If you will create MySQL-MGR, PostgreSQL, Redis, Kafka, or RabbitMQ instances in the console on storage other than TopoLVM, make that storage selectable. See [Storage Classes in the Console](./storage_selection.mdx#console).
4. Create instances by following the documentation of each product under [Alauda Application Services](../index.mdx).
5. Before production, finish the validation: the database stability test for an enterprise SAN, and the pre-production checks for every storage type. See [Validate Storage](./validate_storage.mdx).
