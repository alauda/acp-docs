Alauda Analytical Database E1 is an enterprise-grade real-time analytical database service built on the open-source ClickHouse®. It is a column-oriented OLAP engine for real-time queries and analytics over massive datasets, with cloud-native deployment, operations, and full cluster lifecycle management on Kubernetes.
