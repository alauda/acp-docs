title: About Alauda Cache Service E1
---

Alauda Cache Service E1 is an open-source in-memory data structure storage system that supports various data structures such as strings, hashes, lists, sets, and sorted sets, and provides features like persistence, high availability, and distributed clustering. Due to its high performance and low latency characteristics, It is widely used in scenarios like caching, messaging queues, and real-time data analysis.
