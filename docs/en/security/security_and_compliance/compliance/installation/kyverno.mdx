# Alauda Compliance with Kyverno

Alauda Compliance with Kyverno is a platform service that integrates Kyverno for managing compliance policies on the Alauda Container Platform.

:::note
Starting in ACP 4.5, **Alauda Container Platform Compliance for Kyverno** is named **Alauda Container Platform Policy Management**. Search for **Alauda Container Platform Policy Management** when you download the plugin from the Customer Portal. A plugin package published before the rename still shows **Alauda Container Platform Compliance for Kyverno** in the platform after you upload it.
:::

## Installation Steps

1. Navigate to **Platform Management**
2. In the left navigation bar, click **Marketplace** > **Cluster Plugins**
3. Search for **Alauda Container Platform Policy Management** (shown as **Alauda Container Platform Compliance for Kyverno** for a package published before the rename) and click to view its details
4. Click **Install** to deploy the plugin

## Uninstallation Steps

1. Follow steps 1-3 from the installation process to locate the plugin
2. Click **Uninstall** to remove the plugin
