# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform Compliance for Kyverno.

:::

## Compatibility Matrix

The table below lists the Compliance for Kyverno version documented for ACP 4.4:

| Compliance for Kyverno Version | Supported Alauda Container Platform Version |
| --- | --- |
| v4.3.3 | 4.4.x* |

\* Confirm the exact ACP patch compatibility in the `ACP compatible versions` metadata in the <Term name="company" /> Customer Portal before upgrading.

## Upgrade Path Guidelines

### Upgrade Alongside ACP

- **Description**: When upgrading ACP to 4.4, make the Compliance for Kyverno v4.3.3 package available before starting the ACP upgrade if the package metadata identifies it as an Aligned plugin. If it is Agnostic, upgrade it separately from **Marketplace > Cluster Plugins** after ACP reaches 4.4.
- **Supported ACP Upgrade Path**: `4.3.x -> 4.4.x`
- **Result**: After the upgrade is completed, Compliance for Kyverno is running v4.3.3.

### Patch-Level Upgrade

- **Description**: Upgrades between patch versions in the same Compliance for Kyverno minor version can be performed directly when the target package is compatible with the installed ACP version.
- **Example**: `v4.3.0 -> v4.3.3`
