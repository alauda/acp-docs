# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform Compliance for Kyverno.

:::

## Compatibility Matrix

The table below lists supported versions of the Alauda Container Platform Compliance for Kyverno:

| Compliance for Kyverno Version | Supported Alauda Container Platform Version |
| --- | --- |
| 4.3.3 | 4.2.x, 4.3.x, 4.4.x |

## Upgrade Path Guidelines

### Upgrade Alongside ACP

- **Description**: When upgrading ACP to 4.4.x, make the Compliance for Kyverno 4.3.3 package available before starting the ACP upgrade if the package metadata identifies it as an Aligned plugin. If it is Agnostic, upgrade it separately from **Marketplace > Cluster Plugins** after ACP reaches 4.4.x.
- **Supported ACP Upgrade Path**: `4.3.x -> 4.4.x`
- **Result**: After the upgrade is completed, Compliance for Kyverno is running version 4.3.3.

### Patch-Level Upgrade

- **Description**: Upgrade to Compliance for Kyverno version 4.3.3 when the target package is compatible with the installed ACP version.
- **Example**: Upgrade to Compliance for Kyverno version 4.3.3.
