# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform Policy Management.

:::

## Compatibility Matrix

The table below lists supported versions of the Alauda Container Platform Policy Management:

| Policy Management Version | Supported Alauda Container Platform Version |
| --- | --- |
| 4.3.3 | 4.2.x, 4.3.x, 4.4.x, 4.5.x |

The `ACP compatible versions` field of the package in the Customer Portal is the authority for the compatibility of a specific version. See [Core and Extensions](../../../overview/core-and-extensions.mdx).

## Upgrade Path Guidelines

### Upgrade Alongside ACP

- **Description**: Policy Management has the `Agnostic` lifecycle, so the ACP upgrade does not upgrade it. See [Lifecycle Types](../../../overview/core-and-extensions.mdx#lifecycle-types). Before you upgrade ACP to 4.5.x, confirm in the Compatibility Matrix that the installed Policy Management version supports ACP 4.5.x. If it does not, upgrade Policy Management to version 4.3.3 from **Marketplace > Cluster Plugins** before you upgrade ACP.
- **Supported ACP Upgrade Path**: `4.4.x -> 4.5.x`
- **Result**: After the upgrade is completed, Policy Management is running version 4.3.3.

### Patch-Level Upgrade

- **Description**: Upgrade to Policy Management version 4.3.3 when the target package is compatible with the installed ACP version.
- **Example**: Upgrade to Policy Management version 4.3.3.
