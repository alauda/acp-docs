# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform Policy Management.

:::

## Check Compatibility

Policy Management is released independently of ACP. Before you install or upgrade Policy Management, or upgrade ACP, verify that the exact Policy Management package lists the ACP version in the **ACP compatible versions** field in the **<Term name="company" /> Customer Portal**.

## Upgrade Path Guidelines

### Upgrade Alongside ACP

Policy Management has the `Agnostic` lifecycle, so the ACP upgrade does not upgrade it. See [Lifecycle Types](../../../overview/core-and-extensions.mdx#lifecycle-types).

1. Before you upgrade ACP, check in the Customer Portal whether the package of the installed Policy Management version lists the target ACP version. If it does, Policy Management needs no action for this ACP upgrade.
2. If it does not, download a Policy Management package that lists the target ACP version.
3. Upgrade ACP.
4. After ACP reaches the target version, upgrade Policy Management to the downloaded version, as described in [Upgrade the Plugin](#upgrade-the-plugin).

### Upgrade the Plugin \{#upgrade-the-plugin}

Upgrade Policy Management to a newer version whose package lists the installed ACP version as compatible. Upload the package, then start the upgrade from **Marketplace > Cluster Plugins**, as described in [Cluster Plugin](../../../extend/cluster_plugin.mdx).
