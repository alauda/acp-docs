# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform Compliance for Kyverno.

:::

:::note
Starting in ACP 4.5, **Alauda Container Platform Compliance for Kyverno** is named **Alauda Container Platform Policy Management**. Search for **Alauda Container Platform Policy Management** when you download the plugin from the Customer Portal. A plugin package published before the rename still shows **Alauda Container Platform Compliance for Kyverno** in the platform after you upload it.
:::

## Check Compatibility

Policy Management (previously Compliance for Kyverno) is released independently of ACP. Before you install or upgrade Policy Management, or upgrade ACP, verify that the exact Policy Management package lists the ACP version in the **ACP compatible versions** field in the **<Term name="company" /> Customer Portal**.

## Upgrade Path Guidelines

### Upgrade Alongside ACP

Policy Management is released independently of ACP, so the ACP upgrade does not upgrade it.

1. Before you upgrade ACP, check in the Customer Portal that the package of the installed Policy Management version lists the target ACP version.
2. If it does not, upgrade Policy Management first to a version that lists both the installed and the target ACP versions, as described in [Upgrade the Plugin](#upgrade-the-plugin). If no such version is available, contact technical support.
3. Upgrade ACP.

### Upgrade the Plugin \{#upgrade-the-plugin}

Upgrade Policy Management to a newer version whose package lists the installed ACP version as compatible. Upload the package, then start the upgrade from **Marketplace > Cluster Plugins**, as described in [Cluster Plugin](../../../extend/cluster_plugin.mdx).
