# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform API Refiner.

:::

## Compatibility Matrix

The table below lists supported versions of the Alauda Container Platform API Refiner:

| API Refiner Version | Supported Alauda Container Platform Version |
| --- | --- |
| 4.2.5 | 4.2.x, 4.3.x, 4.4.x |

## Upgrade Path Guidelines

### Upgrade Alongside ACP

- **Description**: When upgrading ACP to 4.4.x, make the API Refiner 4.2.5 package available before starting the ACP upgrade if the package metadata identifies it as an Aligned plugin. If it is Agnostic, upgrade it separately from **Marketplace > Cluster Plugins** after ACP reaches 4.4.x.
- **Supported ACP Upgrade Path**: `4.3.x -> 4.4.x`
- **Result**: After the upgrade is completed, API Refiner is running version 4.2.5.

### Patch-Level Upgrade

- **Description**: Upgrade to API Refiner version 4.2.5 when the target package is compatible with the installed ACP version.
- **Example**: Upgrade to API Refiner version 4.2.5.
