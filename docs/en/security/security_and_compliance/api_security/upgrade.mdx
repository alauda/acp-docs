# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform API Refiner.

:::

## Compatibility Matrix

The table below lists the API Refiner version documented for ACP 4.4:

| API Refiner Version | Supported Alauda Container Platform Version |
| --- | --- |
| v4.2.5 | 4.4.x* |

\* Confirm the exact ACP patch compatibility in the `ACP compatible versions` metadata in the <Term name="company" /> Customer Portal before upgrading.

## Upgrade Path Guidelines

### Upgrade Alongside ACP

- **Description**: When upgrading ACP to 4.4, make the API Refiner v4.2.5 package available before starting the ACP upgrade if the package metadata identifies it as an Aligned plugin. If it is Agnostic, upgrade it separately from **Marketplace > Cluster Plugins** after ACP reaches 4.4.
- **Supported ACP Upgrade Path**: `4.3.x -> 4.4.x`
- **Result**: After the upgrade is completed, API Refiner is running v4.2.5.

### Patch-Level Upgrade

- **Description**: Upgrades between patch versions in the same API Refiner minor version can be performed directly when the target package is compatible with the installed ACP version.
- **Example**: `v4.2.0 -> v4.2.5`
