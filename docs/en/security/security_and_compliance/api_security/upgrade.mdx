# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform API Refiner.

:::

## Compatibility Matrix

The table below lists supported versions of the Alauda Container Platform API Refiner:

| API Refiner Version | Supported Alauda Container Platform Version |
| --- | --- |
| 4.2.5 | 4.2.x, 4.3.x, 4.4.x, 4.5.x |

The `ACP compatible versions` field of the package in the Customer Portal is the authority for the compatibility of a specific version. See [Core and Extensions](../../../overview/core-and-extensions.mdx).

## Upgrade Path Guidelines

### Upgrade Alongside ACP

- **Description**: API Refiner has the `Agnostic` lifecycle, so the ACP upgrade does not upgrade it. See [Lifecycle Types](../../../overview/core-and-extensions.mdx#lifecycle-types). Before you upgrade ACP to 4.6.x, confirm in the Compatibility Matrix that the installed API Refiner version supports ACP 4.6.x. If it does not, upgrade API Refiner from **Marketplace > Cluster Plugins** to a version that supports both the installed and the target ACP versions before you upgrade ACP.
- **Supported ACP Upgrade Path**: `4.5.x -> 4.6.x`
- **Result**: After the upgrade is completed, API Refiner is running a version that supports ACP 4.6.x.

### Patch-Level Upgrade

- **Description**: Upgrade to API Refiner version 4.2.5 when the target package is compatible with the installed ACP version.
- **Example**: Upgrade to API Refiner version 4.2.5.
