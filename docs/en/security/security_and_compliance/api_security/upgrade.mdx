# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform Logging Service.

:::

## Check Compatibility

API Refiner is released independently of ACP. Before you install or upgrade API Refiner, or upgrade ACP, verify that the exact API Refiner package lists the ACP version in the **ACP compatible versions** field in the **<Term name="company" /> Customer Portal**.

## Upgrade Path Guidelines

### Upgrade Alongside ACP

API Refiner is released independently of ACP, so the ACP upgrade does not upgrade it.

1. Before you upgrade ACP, check in the Customer Portal whether the package of the installed API Refiner version lists the target ACP version. If it does, API Refiner needs no action for this ACP upgrade.
2. If it does not, download an API Refiner package that lists the target ACP version.
3. Upgrade ACP.
4. After ACP reaches the target version, upgrade API Refiner to the downloaded version, as described in [Upgrade the Plugin](#upgrade-the-plugin).

### Upgrade the Plugin \{#upgrade-the-plugin}

Upgrade API Refiner to a newer version whose package lists the installed ACP version as compatible. Upload the package, then start the upgrade from **Marketplace > Cluster Plugins**, as described in [Cluster Plugin](../../../extend/cluster_plugin.mdx).
