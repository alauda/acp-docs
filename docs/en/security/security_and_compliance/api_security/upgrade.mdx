# Upgrade

:::info

This document provides the upgrade path principles and supported version compatibility for Alauda Container Platform API Refiner.

:::

## Check Compatibility

API Refiner is released independently of ACP. Before you install or upgrade API Refiner, or upgrade ACP, verify that the exact API Refiner package lists the ACP version in the **ACP compatible versions** field in the **<Term name="company" /> Customer Portal**.

## Upgrade Path Guidelines

### Upgrade Alongside ACP

API Refiner has the `Agnostic` lifecycle, so the ACP upgrade does not upgrade it. See [Lifecycle Types](../../../overview/core-and-extensions.mdx#lifecycle-types).

1. Before you upgrade ACP, check in the Customer Portal that the package of the installed API Refiner version lists the target ACP version.
2. If it does not, upgrade API Refiner first to a version that lists both the installed and the target ACP versions, as described in [Upgrade the Plugin](#upgrade-the-plugin). If no such version is available, contact technical support.
3. Upgrade ACP.

### Upgrade the Plugin \{#upgrade-the-plugin}

Upgrade API Refiner to a newer version whose package lists the installed ACP version as compatible. Upload the package, then start the upgrade from **Marketplace > Cluster Plugins**, as described in [Cluster Plugin](../../../extend/cluster_plugin.mdx).
