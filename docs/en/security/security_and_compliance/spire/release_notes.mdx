# Release Notes

## ACP 4.4 and later

The ACP SPIRE plugin is supported for ACP 4.4 and later. The exact plugin
version is selected from the ACP Marketplace and can change with the ACP
release.

The package includes the SPIRE Server, Controller Manager, Agent, SPIFFE CSI
Driver and OIDC Discovery Provider. The installation is delivered through the
ACP SPIRE ModulePlugin.

## Validated capabilities

- ModulePlugin installation with the documented ACP default trust domain and
  CA values.
- Workload API and SDK identity consumption.
- CSI-mounted Workload API socket consumption.
- A/B mTLS with exact SPIFFE ID authorization and unauthorized C rejection.
- Short-lived SVID renewal and new-connection validation.
- Server, Agent and CSI Driver restart recovery.
- Server PVC persistence and a tested backup/restore procedure.
- Health checks, metrics, logs and common fault troubleshooting.

The release validation package contains the complete deployment manifests,
verification scripts and raw evidence for the corresponding plugin release.
