# Installing Alauda Container Platform Argo Rollouts

:::note
Starting in ACP 4.5, **Alauda Build of Argo Rollouts** is named **Alauda Container Platform Progressive Delivery**. Search for **Alauda Container Platform Progressive Delivery** when you download the plugin from the Customer Portal. A plugin package published before the rename still shows **Alauda Build of Argo Rollouts** in the platform after you upload it.
:::

## Prerequisites

1. **Download** the **Alauda Container Platform Progressive Delivery** (previously **Alauda Build of Argo Rollouts**) cluster plugin installation package corresponding to your platform architecture.
2. **Upload** the installation package using the Upload Packages mechanism.
3. **Install** the installation package to the cluster using the cluster plugins mechanism.

:::info
Upload Packages:
**Administrator** > **Marketplace** > **Upload Packages** page.
Click **Help Document** on the right to get instructions on how to publish the cluster plugin to cluster. For more details, please refer to [CLI](/ui/cli_tools/index.mdx).
:::

## Installing Alauda Container Platform Argo Rollouts

### Procedure

2. Click **Marketplace** > **Cluster Plugins** to enter the **Cluster Plugins** list page.
3. Find the **Alauda Container Platform Progressive Delivery** cluster plugin (shown as **Alauda Build of Argo Rollouts** for a package published before the rename), click **Install**, and navigate to the **Install Alauda Container Platform Progressive Delivery Plugin** page.
4. Simply click **Install** to complete the **Alauda Container Platform Progressive Delivery** cluster plugin installation.
