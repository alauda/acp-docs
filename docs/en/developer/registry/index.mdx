# Registry Image Use

Use this section for developer and workload access to <Term name="productShort" /> Registry for ACP 4.4.

Registry administrator tasks, including installation, configuration, and exposure, are documented in
[Alauda Container Platform Registry administration](../../configure/registry/index.mdx).

## Documentation Structure

| Need | Continue with |
| --- | --- |
| Access the Registry from workloads or external clients. | [Accessing the registry](./accessing_the_registry.mdx) |
| Use `ac` to list, tag, import, mirror, delete, and inspect images. | [Managing images with ac](./managing_images_with_ac.mdx) |
| Review Registry components and administrator settings. | [Registry administration](../../configure/registry/index.mdx) |

## Standard Address

Use the fully qualified internal service address for workloads running in the cluster:

```text
image-registry.image-registry-system.svc:5000
```

Use an external Ingress hostname only for developer machines, CI systems, or other clients outside the cluster. See [Exposing the registry](../../configure/registry/exposing_the_registry.mdx).
