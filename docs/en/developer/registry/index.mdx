# Registry Image Use

<Term name="productShort" /> provides two Registry documentation tracks:

| Track | Use it for | Continue with |
| --- | --- | --- |
| Operator-managed Registry image use | Pull, push, list, tag, and manage images in the current <Term name="productShort" /> Registry. | [Alauda Container Platform Registry](./registry_v2/index.mdx) |
| Legacy Registry workflows | Existing environments that still use the earlier Registry service, `image-registry.cpaas-system.svc`, legacy push limit ConfigMaps, and legacy `ac get images` / `ac delete images` workflows. | [Legacy Registry workflows](./how_to/index.mdx) |

The legacy Registry pages remain available for compatibility. Operator-managed Registry
administrator tasks, including installation, configuration, and exposure, are documented in
[Alauda Container Platform Registry administration](../../configure/registry/registry_v2/index.mdx).
