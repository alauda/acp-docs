# Product and Component Name Changes

Effective with the release of Alauda Container Platform 4.5, Alauda has renamed the products and components listed in this notice. This notice describes the scope of the change and lists the previous name and the new name of each affected product and component.

## Scope of the Change \{#scope}

The change applies to display names only:

- **Alauda Cloud Marketplace** displays the new name for every version of a product or component, including versions published before the change. To download a product or component, search for it by its new name.
- **Packages published before the change** retain the previous name. After such a package is uploaded to Alauda Container Platform, the platform displays the previous name.
- **Package names**, for example `etcd-sync`, are not changed.
- **Documentation** for Alauda Container Platform 4.5 and later refers to each product and component by its new name.

The change does not rename custom resource definitions or the resources that a product or component deploys in a cluster. Existing installations are not affected, and no action is required.

## Suffixes E1 and E2 \{#suffixes}

Some new names end with a suffix such as E1 or E2. The suffix identifies the underlying implementation within a product line. Products whose names differ only in this suffix provide the same capability by using different underlying technologies, for example, Alauda Data Services Cache E1 and Alauda Data Services Cache E2.
