# Plugin Name Reference

The <Term name="company" /> Customer Portal lists every version of a plugin under one name, shown in the **Name on the Customer Portal** column. A plugin package built before that name was introduced still carries the name in the **Name in earlier packages** column, and <Term name="productShort" /> shows that name after you upload the package.

Use the following table to match the two names. Search for the name in the **Name on the Customer Portal** column when you download a plugin. Package names, such as `etcd-sync`, are the same for both names.
