# Install on Alauda OS

The `global` cluster is the platform's control plane: it hosts the registry, the base operator, the cluster registry, and the platform's identity stack, and it manages every workload cluster. This section installs the `global` cluster when its nodes run Alauda OS. To install it on a non-Alauda OS such as Ubuntu or RHEL, see [Install on Non-Alauda OS](../non_alauda_os/index.mdx).

You describe the cluster in one `install-config.yaml`. On a temporary bootstrap node, `ac adm alpha global create` starts a bootstrap cluster, installs the providers into it, creates the `global` cluster, installs the platform, and removes the bootstrap cluster once the `global` cluster has taken over.

## Deployment Path

1. **Prepare.** Meet the [common prerequisites](./prerequisites.mdx), then the prerequisites of your provider.
2. **Install the `global` cluster** on your provider.
3. **Optional: add disaster recovery.** Follow [Disaster Recovery](./disaster_recovery.mdx) before you write either `install-config.yaml`; it covers every provider in one page.
4. **Create workload clusters.** See [Create on Alauda OS](../../workload_clusters/alauda_os/index.mdx).
