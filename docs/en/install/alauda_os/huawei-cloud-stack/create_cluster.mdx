# Create the global Cluster on Huawei Cloud Stack

## Prerequisites \{#prerequisites}

- You completed the [common prerequisites](../prerequisites.mdx) and the [Huawei Cloud Stack prerequisites](./prerequisites.mdx).
- The Core Package is extracted on the bootstrap node and its payload is in the external registry; see [Prepare the Core Package and the Registry](../prerequisites.mdx#prepare-core-package).
- For a disaster recovery pair, write both files as described in [Create a Global Cluster Disaster Recovery Pair](../global_dr.mdx#configure-install-config), then run this procedure on each side.

## Procedure

### 1. Write `install-config.yaml` \{#install-config}

Create an installation directory on the bootstrap node and write `install-config.yaml` in it. Keep the file private (`chmod 600 install-config.yaml`); it holds the passwords.

Copy the following template and fill in the placeholders. The numbered lines are specific to Huawei Cloud Stack and are described below the template; for the other fields, see [Common `install-config.yaml` Fields](../reference.mdx#install-config). For the objects that `ac` renders from this file, see [Rendered Manifests](./reference/install-config-parameters.mdx).

`cluster.network.loadBalancer` is rejected: the control plane endpoint is the ELB under `provider.hcs.elb`.

### 2. Create the Cluster \{#create}

On the bootstrap node:

```bash
<extract-dir>/res/<arch>/ac adm alpha global create --dir <install-dir> --provider hcs
```

`ac` first checks that the IAM endpoint `<schema>://iam-apigateway-proxy.<externalGlobalDomain>` answers. If the check fails, nothing is changed and the error names the endpoint. Make sure the credential and the image, flavor, availability zone, VPC, subnet, and security group names are correct before you run `create`: a wrong credential or name stops the installation in stage 4.

`create` returns when the installation is complete. If `create` stops, run the same command again; completed work is skipped. See [The `create` Command](../reference.mdx#create-command).

### 3. Monitor the Installation \{#monitor}

From another terminal on the bootstrap node:

```bash
<extract-dir>/res/<arch>/ac adm alpha global status
```

For the stages and common failures, see [Troubleshooting](../troubleshooting.mdx); for Huawei Cloud Stack failures, see [Troubleshooting on Huawei Cloud Stack](./troubleshooting.mdx).

## Verification

When `create` returns, the installation is complete, but some platform components can take a few more minutes to become ready. Wait for them as described in [Additional Checks for Alauda OS](../../validation.mdx#alauda-os-checks) before you judge the result, then verify the platform as described in [Validation](../../validation.mdx), including its [checks for Alauda OS](../../validation.mdx#alauda-os-checks).
