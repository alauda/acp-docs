# Create the global Cluster on Huawei Cloud Stack

## Prerequisites \{#prerequisites}

- You completed the [common prerequisites](../prerequisites.mdx) and the [Huawei Cloud Stack prerequisites](./prerequisites.mdx).
- The Core Package is extracted on the bootstrap node and its payload is in the external registry; see [Prepare the Core Package and the Registry](../prerequisites.mdx#prepare-core-package).
- For a disaster recovery pair, write both files as described in [Disaster Recovery](../disaster_recovery.mdx#configure-install-config), then run this procedure on each side.

## Procedure

### 1. Write `install-config.yaml` \{#install-config}

Create an installation directory on the bootstrap node and write `install-config.yaml` in it. Keep the file private (`chmod 600 install-config.yaml`); it holds the passwords.

Copy the following template, fill in the placeholders, and delete the comment blocks you do not use; for the fields, see [Parameters](./reference/install-config-parameters.mdx).

```yaml title="install-config.yaml"
global:                                     # Required: the registry and the platform identity.
  registry:                                 # Required: the external registry that holds all installation artifacts.
    address: <host>:<port>                  # Required: <host>[:<port>], without a scheme or /v2/.
    # Use the following two fields only when the registry requires authentication:
    # username: <user>                      # Required: set together with password.
    # password: <password>                  # Required: set together with username.
    insecureSkipVerify: false               # Default: false. true skips verifying the registry certificate.
    # Default: /root/registry.ca. The registry CA in PEM, an absolute path. It must exist unless insecureSkipVerify is true.
    certificateFile: /root/registry.ca
  platform:                                 # Required: the platform identity and access addresses.
    address: <platform-domain-or-ip>        # Required: without a scheme or port. Disaster recovery requires a domain name.
    username: admin@cpaas.io                # Default: admin@cpaas.io.
    # Required: 8 to 32 characters mixing letters, digits, and symbols. Quote a value that starts with a YAML special character, such as !, *, or &.
    password: <password>
    # Default: []. Other console addresses, without a port. List the control plane VIP to open the console on it. Disaster recovery requires this side's VIP here.
    extraAddresses: []
    # Use the following block only for a third-party console certificate, in one of the two forms. Omit it for a self-signed certificate. Disaster recovery requires it.
    # cert:
    #   # PEM form, with absolute paths:
    #   certificateFile: /root/console.crt
    #   privateKeyFile: /root/console.key
    #   # PKCS#12 form, with an absolute path:
    #   pkcs12CertificateFile: /root/console.pfx
    #   pkcs12Password: <password>

cluster:                                    # Do not add clusterName: ac names the cluster global.
  sshKeys:                                  # Required: the SSH public keys installed on every node.
    - <ssh-public-key>
  # encryptionProviderConfig: <encryption-key>  # Optional: the base64 of a 16, 24, or 32 byte aescbc key. Empty generates a key.
  ntpServers: []                            # Default: []. The NTP servers of the nodes. Empty keeps the image's time configuration.
  network:                                  # Do not add loadBalancer: the control plane endpoint is provider.hcs.elb.
    podCIDR: 10.199.0.0/16                  # Default: 10.199.0.0/16.
    serviceCIDR: 10.96.0.0/12               # Default: 10.96.0.0/12.
    kubeOVN:
      joinCIDR: 100.64.0.0/16               # Default: 100.64.0.0/16. The Pod, Service, and join CIDRs must not overlap.

provider:
  hcs:
    credential:                             # Required: the HCS API credential.
      accessKey: <access-key>               # Required.
      secretKey: <secret-key>               # Required.
      projectID: <project-id>               # Required.
      region: <region>                      # Required.
      externalGlobalDomain: <domain>        # Required: the HCS external domain, without a scheme.
      # schema: https                       # Default: https. Or http.
    imageName: <image-name>                 # Required: the Alauda OS image uploaded to HCS.
    # Required unless every node group sets hcs.flavorName: the default flavor, by its API name. It sets CPU and memory.
    flavorName: <flavor-name>
    # availabilityZone: <az>                # Optional: the default zone. Empty takes the first available zone that HCS reports.
    network:                                # Required: the primary NIC location, shared by all nodes.
      vpcName: <vpc-name>                   # Required.
      securityGroupName: <security-group>   # Required.
      subnetName: <primary-subnet>          # Required: the node subnet, an existing subnet of the VPC.
    elb:                                    # Required: the control plane ELB, which the provider creates.
      vipAddress: <control-plane-vip>       # Required: the control plane VIP, an IPv4 address in the VIP subnet.
      # vipSubnetName: <vip-subnet-name>    # Optional: empty takes network.subnetName.
      l4:                                   # Required: the L4 Hybrid Load Balancing addresses.
        # subnetName: <subnet-name>         # Optional: empty takes network.subnetName.
        ips: [<l4-ip-1>, <l4-ip-2>]         # Required: exactly two distinct IPv4 addresses.
      l7:                                   # Required: the L7 Hybrid Load Balancing addresses.
        # subnetName: <subnet-name>         # Optional: empty takes network.subnetName.
        ips: [<l7-ip-1>, <l7-ip-2>]         # Required: exactly two distinct IPv4 addresses.
    rootDisk:                               # Required unless every node group sets hcs.rootDisk: the system disk of all nodes.
      type: SSD                             # Default: SSD. The EVS type: SSD, SAS, or SATA.
      sizeGiB: <root-disk-gib>              # Required: greater than 0.
    diskType: SSD                           # Default: SSD. The EVS type of the data and persistent disks: SSD, SAS, or SATA.
    # controlPlaneHA:                       # Optional: omit it to spread the control plane across physical hosts with the defaults below.
    #   enabled: true                       # Default: true. false lets HCS place the control plane freely.
    #   policy: soft-anti-affinity          # Default: soft-anti-affinity. Or anti-affinity.

controlPlane:                               # Required: the control plane node group. Do not add cpuCore or memoryGiB: the flavor sets them.
  # Required: an odd number, 1 or 3 or more. A cluster with a single control plane node is for testing and cannot be upgraded.
  replicas: 3
  deployMode: normal                        # Default: normal. base dedicates this node group to the platform.
  # Use the following block only when this node group differs from provider.hcs:
  # hcs:
  #   flavorName: <flavor-name>             # Optional: overrides provider.hcs.flavorName.
  #   availabilityZone: <az>                # Optional: overrides provider.hcs.availabilityZone.
  #   subnetName: <subnet-name>             # Optional: overrides provider.hcs.network.subnetName.
  #   rootDisk:                             # Optional: replaces provider.hcs.rootDisk. Set both fields.
  #     type: SSD
  #     sizeGiB: <root-disk-gib>
  network:                                  # Do not add gateway, dns, or mask: the subnet supplies them.
    additions: []                           # Default: []. The additional NICs, matched in order to hosts[].additionalIps.
    # To add NICs, replace "additions: []" with the following block:
    # additions:
    #   - hcs:
    #       subnetName: <additional-subnet>  # Optional: empty takes this node group's subnet.
  disks:                                    # Required: keep the standard disk names and set sizeGiB.
    ephemeral:                              # Required: disks recreated with the instance.
      - name: var-lib-containerd
        sizeGiB: 100
      - name: var-lib-kubelet
        sizeGiB: 100
      - name: var-lib-etcd                  # Control plane only.
        sizeGiB: 20
    persistent:                             # Required: disks kept when the instance is replaced.
      - name: var-cpaas
        sizeGiB: 100
    rawDisks: []                            # Default: []. Raw block volumes for TopoLVM.
    # To add raw disks, replace "rawDisks: []" with the following block:
    # rawDisks:
    #   - name: data-001                    # Required: a name of your choice.
    #     sizeGiB: 50                       # Required: greater than 0.
    # Use the following block only to override provider.hcs.diskType for this node group:
    # hcs:
    #   type: SSD                           # Optional: overrides provider.hcs.diskType.
  hosts:                                    # Required: at least replicas entries.
    - hostname: <cp-0-hostname>             # Required.
      ip: <cp-0-ip>                         # Required: the primary NIC address, IPv4.
      additionalIps: []                     # Default: []. One IPv4 address per network.additions entry, in order.
    - hostname: <cp-1-hostname>
      ip: <cp-1-ip>
      additionalIps: []
    - hostname: <cp-2-hostname>
      ip: <cp-2-ip>
      additionalIps: []

computes:                                   # Optional: the worker node groups. Delete this section to run on the control plane nodes alone.
  - name: worker                            # Required: a DNS-1123 label, unique per group. control-plane is reserved.
    replicas: 3                             # Required: the number of nodes in this group.
    deployMode: normal                      # Default: normal. base dedicates this node group to the platform.
    # Use the following block only when this node group differs from provider.hcs:
    # hcs:
    #   flavorName: <flavor-name>           # Optional: overrides provider.hcs.flavorName.
    #   availabilityZone: <az>              # Optional: overrides provider.hcs.availabilityZone.
    #   subnetName: <subnet-name>           # Optional: overrides provider.hcs.network.subnetName.
    #   rootDisk:                           # Optional: replaces provider.hcs.rootDisk. Set both fields.
    #     type: SSD
    #     sizeGiB: <root-disk-gib>
    network:                                # Do not add gateway, dns, or mask: the subnet supplies them.
      additions: []                         # Default: []. The additional NICs, matched in order to hosts[].additionalIps.
      # To add NICs, replace "additions: []" with the following block:
      # additions:
      #   - hcs:
      #       subnetName: <additional-subnet>  # Optional: empty takes this node group's subnet.
    disks:                                  # Required: keep the standard disk names and set sizeGiB.
      ephemeral:                            # Required: disks recreated with the instance. Workers have no var-lib-etcd.
        - name: var-lib-containerd
          sizeGiB: 100
        - name: var-lib-kubelet
          sizeGiB: 100
      persistent:                           # Required: disks kept when the instance is replaced.
        - name: var-cpaas
          sizeGiB: 100
      rawDisks: []                          # Default: []. Raw block volumes for TopoLVM.
      # To add raw disks, replace "rawDisks: []" with the following block:
      # rawDisks:
      #   - name: data-001                  # Required: a name of your choice.
      #     sizeGiB: 50                     # Required: greater than 0.
      # Use the following block only to override provider.hcs.diskType for this node group:
      # hcs:
      #   type: SSD                         # Optional: overrides provider.hcs.diskType.
    hosts:                                  # Required: at least replicas entries.
      - hostname: <worker-0-hostname>       # Required.
        ip: <worker-0-ip>                   # Required: the primary NIC address, IPv4.
        additionalIps: []                   # Default: []. One IPv4 address per network.additions entry, in order.
      - hostname: <worker-1-hostname>
        ip: <worker-1-ip>
        additionalIps: []
      - hostname: <worker-2-hostname>
        ip: <worker-2-ip>
        additionalIps: []
```

For disaster recovery, `global.platform.address` is a domain name, and `global.platform.cert`, `global.platform.extraAddresses`, `cluster.encryptionProviderConfig`, and `provider.hcs.elb.vipAddress` take the values in [Disaster Recovery](../disaster_recovery.mdx#configure-install-config).

### 2. Create the Cluster \{#create}

On the bootstrap node:

```bash
<extract-dir>/res/<arch>/ac adm alpha global create --dir <install-dir> --provider hcs
```

`ac` first checks that the IAM endpoint `<schema>://iam-apigateway-proxy.<externalGlobalDomain>` answers. If the check fails, nothing is changed and the error names the endpoint. Make sure the credential and the image, flavor, availability zone, VPC, subnet, and security group names are correct before you run `create`: a wrong credential or name stops the installation in stage 4.

`create` returns when the installation is complete. If `create` stops, run the same command again; completed work is skipped. See [The `create` Command](../reference.mdx#create-command).

### 3. Monitor the Installation \{#monitor}

From another terminal on the bootstrap node:

```bash
<extract-dir>/res/<arch>/ac adm alpha global status
```

For the stages and common failures, see [Troubleshooting](../troubleshooting.mdx); for Huawei Cloud Stack failures, see [Troubleshooting on Huawei Cloud Stack](./troubleshooting.mdx).

## Verification

When `create` returns, the installation is complete. Verify the platform as described in [Validation](../../validation.mdx), including its [checks for Alauda OS](../../validation.mdx#alauda-os-checks).
