# Prerequisites for Huawei Cloud Stack

Complete the [common prerequisites](../prerequisites.mdx) first, then prepare the following on Huawei Cloud Stack. `ac` creates none of them. For where to get each value, see [HCS Credential Secret](../../../workload_clusters/alauda_os/huawei-cloud-stack/prerequisites.mdx#credential-secret) and [HCS Objects, Quota, and Node Addresses](../../../workload_clusters/alauda_os/huawei-cloud-stack/prerequisites.mdx#hcs-inputs). On the `global` cluster, the credential goes in `install-config.yaml`, not in a Secret.

- **An HCS API credential**: the access key and secret key, the project ID, the region, and the external global domain of the HCS deployment.
- **An image created from the Alauda OS image**. It must carry the Kubernetes version of the Core Package, and its architecture must match the flavors; see [OS Support Matrix](../../../overview/alauda_os_support_matrix.mdx).
- **The ECS flavors** for the control plane and each worker group, by their API names.
- **A VPC, a security group, and every subnet** that `install-config.yaml` names: the node subnet, and any subnet for the ELB, an additional NIC, or a node group.
- **Security group rules** that allow the node-to-node ports in [Communication Matrix](../../prepare/communication_matrix.mdx), and traffic from the ELB to the control plane nodes on `TCP/6443`, `TCP/11780`, `TCP/11443`, `TCP/2379`, and `TCP/443`.
- **Static IPv4 addresses and hostnames**: the control plane VIP, two L4 and two L7 addresses for the ELB, and one address and one hostname per node.
- **Quota** for the instances, the EVS disks, the ELB, and the server group. Confirm it before you create the cluster.
- **The bootstrap node and the `global` nodes reach the HCS service endpoints** `ecs.<region>.<externalGlobalDomain>`, `evs.<region>.<externalGlobalDomain>`, and `vpc.<region>.<externalGlobalDomain>` on `TCP/443`, whatever `schema` is.
- **The bootstrap node reaches the IAM endpoint** `iam-apigateway-proxy.<externalGlobalDomain>` on `TCP/443`, or `TCP/80` for `schema: http`.
