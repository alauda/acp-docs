# Overview of the global Cluster on Huawei Cloud Stack

On Huawei Cloud Stack, the `global` cluster runs on ECS instances that the HCS provider creates from one image, each with the address you list in `install-config.yaml`. The provider also creates the control plane ELB. `ac adm alpha global create` creates the instances and the ELB, installs the platform, and hands the cluster over from the bootstrap cluster in one run.

| Step | Page |
|---|---|
| 1. Prepare the API credential, the image, the flavors, the network objects, the addresses, and quota | [Prerequisites](./prerequisites.mdx) |
| 2. Write `install-config.yaml` and install | [Create the global Cluster](./create_cluster.mdx) |
| 3. Optional: install a standby `global` cluster | [Disaster Recovery](../disaster_recovery.mdx) |
| When the installation does not advance | [Troubleshooting](./troubleshooting.mdx) |
| Remove the cluster, its instances, and its ELB | [Delete the global Cluster](./deleting.mdx) |
