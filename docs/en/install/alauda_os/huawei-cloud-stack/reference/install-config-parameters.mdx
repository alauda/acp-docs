# Objects Rendered from install-config.yaml on Huawei Cloud Stack

This page lists the objects that `ac` renders from the `global` cluster's `install-config.yaml` on Huawei Cloud Stack. The Huawei Cloud Stack fields are described below the template in [Write `install-config.yaml`](../create_cluster.mdx#install-config). The fields that all providers share are described in [Common `install-config.yaml` Fields](../../reference.mdx#install-config).

## Rendered Manifests \{#rendered-manifests}

`ac adm alpha global manifests` writes the following objects to `manifests/`. All of them are in the `cpaas-system` namespace. For their API fields, see the [Provider APIs](../../../../apis/kubernetes_apis/infrastructure_providers/huawei-cloud-stack/index.mdx).

| Object | Name | Notes |
|---|---|---|
| `Secret` | `global-encryption-provider-config` | The encryption configuration, referenced by `HCSCluster`. |
| `Secret` | `global-credential` | The HCS API credential, referenced by `HCSCluster.spec.identityRef`. |
| `Cluster` | `global` | |
| `HCSCluster` | `global` | The network, the subnets, the control plane ELB, and `controlPlaneHA`. `ac` does not write `controlPlaneEndpoint`. The provider sets it from the ELB. |
| `KubeadmControlPlane`, `HCSMachineTemplate`, `HCSMachineConfigPool` | `global-control-plane` | The pool holds each node's address, hostname, and persistent and raw disks. |
| `MachineDeployment`, `HCSMachineTemplate`, `HCSMachineConfigPool` | `global-<group>` | One set per `computes` entry. |
| `KubeadmConfigTemplate` | `global-<group>-config` | One per `computes` entry. |
| `ConfigMap` | `dcs-import-extra-resources` | The manifest that the installer reads before it hands the cluster over. The name is the same on every provider. |

The ephemeral disks are data volumes of the `HCSMachineTemplate`. They are formatted as xfs and recreated with the instance. `var-cpaas` and the raw disks are declared in the `HCSMachineConfigPool`, so they are kept when an instance is replaced. Raw disks have no mount path.

Do not delete the `global-credential` or `global-encryption-provider-config` Secret on the `global` cluster. Without them, new control plane machines cannot be created.
