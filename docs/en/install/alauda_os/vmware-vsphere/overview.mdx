# Overview of the global Cluster on VMware vSphere

On VMware vSphere, the `global` cluster runs on VMs that the provider clones from an Alauda OS VM template, each with the static address you list in `install-config.yaml`. The control plane endpoint is your load balancer or a Self-built VIP that the provider runs on the control plane nodes. `ac adm alpha global create` creates the VMs, installs the platform, and hands the cluster over from the bootstrap cluster in one run.
