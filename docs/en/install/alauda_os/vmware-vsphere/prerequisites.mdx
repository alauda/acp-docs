# Prerequisites for VMware vSphere

Complete the [common prerequisites](../prerequisites.mdx) first, then prepare the following in VMware vSphere. `ac` creates none of them.

- **A vCenter account** that can read the inventory, and clone, power, reconfigure, and delete VMs and their disks. The vSphere cloud provider (CPI) uses the same account.
- **A VM template created from the Alauda OS image**, by name or inventory path. It must carry the Kubernetes version of the Core Package; see [OS Support Matrix](../../../overview/alauda_os_support_matrix.mdx) and [VM template requirements](../../../workload_clusters/alauda_os/vmware-vsphere/prerequisites.mdx#vm-template-requirements). Register the VM template on the `global` cluster with a ConfigMap; see [VM Template ConfigMap](../../../workload_clusters/alauda_os/vmware-vsphere/prerequisites.mdx#vm-template-configmap).
- **The datacenter, the datastore, and the port group** of the primary NIC, and the port group of each additional NIC if you use them.
- **The VM folder**, if you place the VMs in one.
- **The compute resource**: the DRS cluster or standalone host the VMs run on. It is required when the datacenter has more than one.
- **Static IPv4 addresses and hostnames** for every node, with the gateway, prefix length, and DNS servers of each network.
- **A control plane endpoint**, as planned in [Plan the Control Plane Endpoint](../prerequisites.mdx#control-plane-endpoint): a Self-built VIP with its VRID, or an external load balancer that forwards the ports marked **Yes** in **Forward on load balancer** in [Platform Access Address and `global` VIP](../../prepare/communication_matrix.mdx#global_vip).
- **Network access** from the bootstrap node and the `global` nodes to vCenter, as listed in [VMware vSphere](../../prepare/communication_matrix.mdx#provider-vsphere).

## Next Steps

You now have, in addition to the common values, the vCenter account, the VM template, the datacenter, datastore, and port groups, the VM folder and compute resource if you use them, and the node addresses and hostnames. Continue with [Create the global Cluster on VMware vSphere](./create_cluster.mdx).
