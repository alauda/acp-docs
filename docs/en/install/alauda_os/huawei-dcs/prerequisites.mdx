# Prerequisites for Huawei DCS

Complete the [common prerequisites](../prerequisites.mdx) first. On Huawei DCS, the provider clones every node from one VM template and gives it the static address you list in `install-config.yaml`. Prepare the following on DCS. `ac` creates none of them; its preflight checks look each one up before anything changes on the bootstrap node, and report every missing one.

- **A DCS API account**: the FusionCompute endpoint, user, password, and site ID.
- **A VM template created from the Alauda OS image** published for the platform release, without changes; see [Downloading Alauda OS](../../../overview/alauda_os_support_matrix.mdx#downloading-alauda-os). For an Alauda OS K template, see [Alauda OS K Templates](../../../workload_clusters/alauda_os/huawei-dcs/reference/install-config-parameters.mdx#alauda-os-k).
- **The VM folder** for the nodes.
- **A distributed virtual switch and a port group on it** for the node network, and one for each additional NIC.
- **The datastore or datastore cluster** for the disks, and the datastore for the CD-ROM if you name one.
- **The compute cluster or host**, if you pin the nodes with `resource`. Preflight checks only the name, not the capacity or health.
- **Static IPv4 addresses and hostnames** for every node, with the gateway, prefix length, and DNS server of each network.
- **A control plane endpoint.** With `external`, the default, your load balancer forwards `TCP/6443` to the control plane nodes. With `internal`, the provider runs the VIP on the control plane nodes: reserve an unused IPv4 address in the control plane Layer 2 domain and a `vrid` that no other VRRP instance in it uses. See [Plan the Control Plane Endpoint](../../../workload_clusters/alauda_os/prepare/control-plane-endpoint.mdx).
- **The bootstrap node reaches the DCS VRM on `TCP/7443`** and the management address of the DCS hosts, typically `TCP/8443`.

## Control Plane Spread \{#control-plane-ha}

`controlPlaneHA: true` spreads the control plane VMs across DCS hosts with a DRS rule. It needs DRS on the compute cluster, enough hosts, and a datastore shared by them, as listed in [DCS Objects, Capacity, and Addresses](../../../workload_clusters/alauda_os/huawei-dcs/prerequisites.mdx#dcs-objects).
