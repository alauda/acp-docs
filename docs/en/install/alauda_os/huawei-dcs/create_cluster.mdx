# Create the global Cluster on Huawei DCS

## Prerequisites \{#prerequisites}

- You completed the [common prerequisites](../prerequisites.mdx) and the [Huawei DCS prerequisites](./prerequisites.mdx).
- The Core Package is extracted on the bootstrap node and its payload is in the external registry; see [Prepare the Core Package and the Registry](../prerequisites.mdx#prepare-core-package).
- For a disaster recovery pair, write both files as described in [Disaster Recovery](../disaster_recovery.mdx#configure-install-config), then run this procedure on each side.

## Procedure

### 1. Write `install-config.yaml` \{#install-config}

Create an installation directory on the bootstrap node and write `install-config.yaml` in it. Keep the file private (`chmod 600 install-config.yaml`); it holds the passwords.

Copy the following template, fill in the placeholders, and delete the comment blocks you do not use; for the fields, see [Parameters](./reference/install-config-parameters.mdx).

{/* eslint-disable mdx/remark -- the ac field name contains a legacy OS name */}

```yaml title="install-config.yaml"
global:                                     # Required: the registry and the platform identity.
  registry:                                 # Required: the external registry that holds all installation artifacts.
    address: <host>:<port>                  # Required: <host>[:<port>], without a scheme or /v2/.
    # Use the following two fields only when the registry requires authentication:
    # username: <user>                      # Required: set together with password.
    # password: <password>                  # Required: set together with username.
    insecureSkipVerify: false               # Default: false. true skips verifying the registry certificate.
    # Default: /root/registry.ca. The registry CA in PEM, an absolute path. It must exist unless insecureSkipVerify is true.
    certificateFile: /root/registry.ca
  platform:                                 # Required: the platform identity and access addresses.
    address: <platform-domain-or-ip>        # Required: without a scheme or port. Disaster recovery requires a domain name.
    username: admin@cpaas.io                # Default: admin@cpaas.io.
    # Required: 8 to 32 characters mixing letters, digits, and symbols. Quote a value that starts with a YAML special character, such as !, *, or &.
    password: <password>
    # Default: []. Other console addresses, without a port. List the control plane VIP to open the console on it. Disaster recovery requires this side's VIP here.
    extraAddresses: []
    # Use the following block only for a third-party console certificate, in one of the two forms. Omit it for a self-signed certificate. Disaster recovery requires it.
    # cert:
    #   # PEM form, with absolute paths:
    #   certificateFile: /root/console.crt
    #   privateKeyFile: /root/console.key
    #   # PKCS#12 form, with an absolute path:
    #   pkcs12CertificateFile: /root/console.pfx
    #   pkcs12Password: <password>

cluster:                                    # Do not add clusterName: ac names the cluster global.
  sshKeys:                                  # Required: the SSH public keys installed on every node.
    - <ssh-public-key>
  # encryptionProviderConfig: <encryption-key>  # Optional: the base64 of a 16, 24, or 32 byte aescbc key. Empty generates a key.
  ntpServers: []                            # Default: []. The NTP servers of the nodes. Empty keeps the image's time configuration.
  network:
    podCIDR: 10.199.0.0/16                  # Default: 10.199.0.0/16.
    serviceCIDR: 10.96.0.0/12               # Default: 10.96.0.0/12.
    kubeOVN:
      joinCIDR: 100.64.0.0/16               # Default: 100.64.0.0/16. The Pod, Service, and join CIDRs must not overlap.
    loadBalancer:                           # Required: the control plane endpoint.
      type: external                        # Default: external. Set internal for a Self-built VIP.
      # Required: the load balancer address, or the VIP with type: internal. An IPv4 address that is not a node address and is outside the CIDRs above.
      address: <control-plane-endpoint>
      port: 6443                            # Default: 6443.
      # Use the following two fields only with type: internal:
      # vrid: <vrid>                        # Required: 1 to 255, unique in the control plane Layer 2 domain.
      # interface: <nic-name>               # Optional: the NIC that carries the VIP. Empty uses the NIC that carries the node IP.

provider:
  dcs:
    credential:                             # Required: the DCS API credential.
      endpoint: https://<fc-address>:7443   # Required: https://, with the port and without a trailing slash.
      authUser: <user>                      # Required: the DCS user name.
      authKey: <password>                   # Required: the plain-text password, not the SHA-256 digest.
      site: <site-id>                       # Required: the bare site ID, not urn:sites:...
      userType: interconnect                # Default: interconnect. Or domain.
    # Required: the VM template every node is cloned from, created from an Alauda OS image of version 4.2.1 or later.
    vmTemplateName: <vm-template-name>
    # Required: true or false. true keeps the control plane VMs on different DCS hosts; see the Huawei DCS prerequisites for what it needs.
    controlPlaneHA: <control-plane-ha>
    machineFolder: <folder-name>            # Required: an existing DCS VM folder.
    # cdRomDatastoreName: <datastore>       # Optional: the datastore for each node's CD-ROM. Empty lets the provider choose.
    # Default: false. Set true when vmTemplateName is an Alauda OS K template; otherwise the VMs boot without a network.
    # kubeOS: true
    # rootDisk:                             # Optional: the system disk. Empty keeps the template's size.
    #   sizeGiB: <root-disk-gib>            # Required: DCS rejects a size smaller than the template's.
    # resource:                             # Optional: fixes the VMs to an existing compute resource. Empty lets DCS place them.
    #   type: cluster                       # Required: cluster for a compute cluster, or host for a physical host.
    #   name: <cluster-or-host-name>        # Required.
    network:                                # Required: the primary NIC of every node.
      dvSwitchName: <dv-switch-name>        # Required: the distributed virtual switch.
      portGroupName: <port-group-name>      # Required: a port group of that switch.
    disks:
      datastore:
        type: <datastore-type>              # Required: Datastore or DatastoreCluster.
        name: <datastore-name>              # Required: the datastore or datastore cluster name.
      isThin: false                         # Default: false, thick provisioning. Applies to persistent and raw disks only.
      pciType: VIRTIO                       # Default: VIRTIO. VIRTIO, SCSI, or IDE.

controlPlane:                               # Required: the control plane node group.
  # Required: an odd number, 1 or 3 or more. With fewer than three control plane nodes, contact technical support before you upgrade the cluster.
  replicas: 3
  cpuCore: 8                                # Default: 8.
  memoryGiB: 16                             # Default: 16.
  deployMode: normal                        # Default: normal. base dedicates this node group to the platform.
  # Use the following block only when this node group differs from provider.dcs:
  # dcs:
  #   machineFolder: <folder-name>          # Optional: overrides provider.dcs.machineFolder.
  #   cdRomDatastoreName: <datastore>       # Optional: overrides provider.dcs.cdRomDatastoreName.
  #   rootDisk:                             # Optional: overrides provider.dcs.rootDisk.
  #     sizeGiB: <root-disk-gib>
  #   resource:                             # Optional: overrides provider.dcs.resource. Set both fields.
  #     type: cluster
  #     name: <cluster-or-host-name>
  network:                                  # Required: the primary NIC network of this node group.
    gateway: <cp-gateway>                   # Required: the primary NIC gateway.
    # dns: [<dns-ip>]                       # Optional: DCS uses only the first entry.
    mask: <prefix-length>                   # Required: a prefix length from 1 to 32.
    additions: []                           # Default: []. The additional NICs, matched in order to hosts[].additionalIps.
    # To add NICs, replace "additions: []" with the following block:
    # additions:
    #   - mask: <prefix-length>             # Optional: 1 to 32. Empty takes network.mask.
    #     dcs:                              # Optional: empty takes provider.dcs.network.
    #       dvSwitchName: <dv-switch-name>
    #       portGroupName: <port-group-name>
  disks:                                    # Required: keep the standard disk names and set sizeGiB.
    ephemeral:                              # Required: disks recreated with the VM.
      - name: var-lib-containerd
        sizeGiB: 100
      - name: var-lib-kubelet
        sizeGiB: 100
      - name: var-lib-etcd                  # Control plane only.
        sizeGiB: 20
    persistent:                             # Required: disks kept when the VM is replaced.
      - name: var-cpaas
        sizeGiB: 100
    rawDisks: []                            # Default: []. Raw block volumes for TopoLVM.
    # To add raw disks, replace "rawDisks: []" with the following block:
    # rawDisks:
    #   - name: data-001                    # Required: a name of your choice.
    #     sizeGiB: 50                       # Required: greater than 0.
    # Use the following block only when this node group differs from provider.dcs.disks. Set only the fields that differ:
    # dcs:
    #   datastore:                          # Optional: overrides provider.dcs.disks.datastore. Set both fields.
    #     type: <datastore-type>
    #     name: <datastore-name>
    #   isThin: true                        # Optional: overrides provider.dcs.disks.isThin.
    #   pciType: VIRTIO                     # Optional: overrides provider.dcs.disks.pciType.
  hosts:                                    # Required: at least replicas entries.
    - hostname: <cp-0-hostname>             # Required.
      ip: <cp-0-ip>                         # Required: the primary NIC address, IPv4.
      additionalIps: []                     # Default: []. One IPv4 address per network.additions entry, in order.
    - hostname: <cp-1-hostname>
      ip: <cp-1-ip>
      additionalIps: []
    - hostname: <cp-2-hostname>
      ip: <cp-2-ip>
      additionalIps: []

computes:                                   # Optional: the worker node groups. Delete this section to run on the control plane nodes alone.
  - name: worker                            # Required: a DNS-1123 label, unique per group. control-plane is reserved.
    replicas: 3                             # Required: the number of nodes in this group.
    cpuCore: 8                              # Default: 8.
    memoryGiB: 16                           # Default: 16.
    deployMode: normal                      # Default: normal. base dedicates this node group to the platform.
    # Use the following block only when this node group differs from provider.dcs:
    # dcs:
    #   machineFolder: <folder-name>        # Optional: overrides provider.dcs.machineFolder.
    #   cdRomDatastoreName: <datastore>     # Optional: overrides provider.dcs.cdRomDatastoreName.
    #   rootDisk:                           # Optional: overrides provider.dcs.rootDisk.
    #     sizeGiB: <root-disk-gib>
    #   resource:                           # Optional: overrides provider.dcs.resource. Set both fields.
    #     type: cluster
    #     name: <cluster-or-host-name>
    network:                                # Required: the primary NIC network of this node group.
      gateway: <worker-gateway>             # Required: the primary NIC gateway.
      # dns: [<dns-ip>]                     # Optional: DCS uses only the first entry.
      mask: <prefix-length>                 # Required: a prefix length from 1 to 32.
      additions: []                         # Default: []. The additional NICs, matched in order to hosts[].additionalIps.
      # To add NICs, replace "additions: []" with the following block:
      # additions:
      #   - mask: <prefix-length>           # Optional: 1 to 32. Empty takes network.mask.
      #     dcs:                            # Optional: empty takes provider.dcs.network.
      #       dvSwitchName: <dv-switch-name>
      #       portGroupName: <port-group-name>
    disks:                                  # Required: keep the standard disk names and set sizeGiB.
      ephemeral:                            # Required: disks recreated with the VM. Workers have no var-lib-etcd.
        - name: var-lib-containerd
          sizeGiB: 100
        - name: var-lib-kubelet
          sizeGiB: 100
      persistent:                           # Required: disks kept when the VM is replaced.
        - name: var-cpaas
          sizeGiB: 100
      rawDisks: []                          # Default: []. Raw block volumes for TopoLVM.
      # To add raw disks, replace "rawDisks: []" with the following block:
      # rawDisks:
      #   - name: data-001                  # Required: a name of your choice.
      #     sizeGiB: 50                     # Required: greater than 0.
      # Use the following block only when this node group differs from provider.dcs.disks. Set only the fields that differ:
      # dcs:
      #   datastore:                        # Optional: overrides provider.dcs.disks.datastore. Set both fields.
      #     type: <datastore-type>
      #     name: <datastore-name>
      #   isThin: true                      # Optional: overrides provider.dcs.disks.isThin.
      #   pciType: VIRTIO                   # Optional: overrides provider.dcs.disks.pciType.
    hosts:                                  # Required: at least replicas entries.
      - hostname: <worker-0-hostname>       # Required.
        ip: <worker-0-ip>                   # Required: the primary NIC address, IPv4.
        additionalIps: []                   # Default: []. One IPv4 address per network.additions entry, in order.
      - hostname: <worker-1-hostname>
        ip: <worker-1-ip>
        additionalIps: []

        ip: <worker-2-ip>
        additionalIps: []
```

### 2. Create the Cluster \{#create}

On the bootstrap node:

```bash
<extract-dir>/res/<arch>/ac adm alpha global create --dir <install-dir> --provider dcs
```

`ac` first checks the DCS sign-in, the DCS objects named in `install-config.yaml`, and the registry. If a check fails, nothing is changed and the error names the item. Make sure that an `external` load balancer is ready before you run `create`.

:::warning
Make sure the password in `install-config.yaml` is correct before you run `create`: DCS locks the account after repeated failed sign-ins.
:::

`create` returns when the installation is complete. If `create` stops, run the same command again; completed work is skipped. See [The `create` Command](../reference.mdx#create-command).

### 3. Monitor the Installation \{#monitor}

From another terminal on the bootstrap node:

```bash
<extract-dir>/res/<arch>/ac adm alpha global status
```

For the stages and common failures, see [Troubleshooting](../troubleshooting.mdx); for Huawei DCS failures, see [Troubleshooting on Huawei DCS](./troubleshooting.mdx).

## Verification

When `create` returns, the installation is complete. Verify the platform as described in [Validation](../../validation.mdx), including its [checks for Alauda OS](../../validation.mdx#alauda-os-checks).

**Applies to**: a Self-built VIP (`cluster.network.loadBalancer.type: internal`). Skip it with an `external` load balancer.

On a control plane node of the `global` cluster:

```bash
curl --cacert /etc/kubernetes/pki/ca.crt https://<control-plane-vip>:6443/healthz
```

Continue when it prints `ok`; otherwise see [Troubleshooting on Huawei DCS](./troubleshooting.mdx).
