# Delete the global Cluster on Bare Metal

`ac adm alpha global destroy` does not support Bare Metal: it stops without deleting anything.

To reclaim the hosts, reinstall or wipe them, or retire them. Before a host is used again for a cluster, wipe its system disk and remove leftover `COS_*` partition labels, as described in [Prerequisites](./prerequisites.mdx#hosts).
