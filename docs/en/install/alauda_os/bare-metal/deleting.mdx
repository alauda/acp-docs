# Delete the global Cluster on Bare Metal

`ac adm alpha global destroy` does not support Bare Metal: it stops without deleting anything.

To reclaim the hosts, reinstall them or retire them. A host that boots an installation ISO again wipes the earlier Alauda OS installation on its other disks automatically; put the ISO first in its boot order so that the host does not start the old system. See [Prerequisites](./prerequisites.mdx#hosts).
