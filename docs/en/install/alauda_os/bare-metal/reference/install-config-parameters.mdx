# install-config.yaml Parameters for Bare Metal

This page lists the Bare Metal fields of the `global` cluster's `install-config.yaml` and the objects that `ac` renders from them. The fields that every provider shares are in [Installation Reference](../../reference.mdx#install-config).

## Bare Metal Fields \{#fields}

| Field | Required | Default | Description |
|---|---|---|---|
| `global.bootstrapIP` | Yes | — | The IPv4 address of the bootstrap node that the hosts route to. It is the registration endpoint, `https://<bootstrapIP>:12443`. |
| `cluster.network.loadBalancer.type` | No | `internal` | `internal` for the provider-managed VIP, `external` for your load balancer. |
| `cluster.network.loadBalancer.vrid` | For `internal` | — | 0-255, unique in the control plane Layer 2 domain. `0` is valid. |
| `cluster.network.loadBalancer.interface`, `vipMode` | Not supported | — | The provider binds the VIP to the interface that carries the node address. |
| `provider.baremetal.isoImageTag` | Yes | — | The tag of `tkestack/baremetal-base-image-iso`. Write the tag only, without registry or repository. |
| `provider.baremetal.rootImageTag` | Yes | — | The tag of `tkestack/baremetal-base-image`. It may differ from `isoImageTag`. |
| `provider.baremetal.emulateTPM` | No | `true` | Register hosts with an emulated TPM. Set `false` only when every host has a hardware TPM you want to use. |
| `provider.baremetal.serviceAccountSigningKey` | No | Generated | The base64 of the PEM private key that signs ServiceAccount tokens. Set it only for a disaster recovery pair; see [Disaster Recovery on Bare Metal](../../disaster_recovery.mdx#configure-install-config). |
| `controlPlane.replicas` | Yes | — | An odd number: `1`, or `3` or more. The control plane runs stacked etcd. With fewer than three control plane nodes, contact technical support before you upgrade the cluster. |
| `controlPlane.baremetal.machineInventoryPool`, `computes[].baremetal.machineInventoryPool` | Yes | — | The `MachineInventoryPool` each node group draws from. Two node groups cannot share a pool. |
| `computes[].name` | Yes | — | Unique per group. `control-plane` is reserved. |

The node groups take no `cpuCore`, `memoryGiB`, `network`, `disks`, or `hosts` fields; writing one is an error. `credentialRef` is rejected as well.

## Rendered Manifests \{#rendered-manifests}

`ac adm alpha global manifests` writes the following objects to `manifests/`, all in `cpaas-system`. Field-level reference: [Bare Metal Provider](../../../../workload_clusters/alauda_os/bare-metal/overview.mdx).

| Object | Name | Notes |
|---|---|---|
| `Secret` | `global-sa` | Only when `serviceAccountSigningKey` is set. `ac` refuses to overwrite an existing `global-sa` that holds a different key. |
| `Secret` | `global-encryption-provider-config` | The encryption configuration, referenced by `BaremetalCluster`. |
| `Cluster` | `global` | Labelled `cluster-type: ProviderBaremetal`. |
| `BaremetalCluster` | `global` | The control plane load balancer and the encryption Secret reference. |
| `KubeadmControlPlane`, `BaremetalMachineTemplate` | `global-control-plane` | The template references `controlPlane.baremetal.machineInventoryPool`. |
| `MachineDeployment`, `BaremetalMachineTemplate` | `global-<group>` | One set per `computes` entry. |
| `KubeadmConfigTemplate` | `global-<group>-config` | One per `computes` entry. |

`create` also creates objects in the bootstrap cluster that are not part of `manifests/`:

| Object | Name | Purpose |
|---|---|---|
| `MachineRegistration` | `global-registration` | The registration the hosts enrol through. Hosts register as `MachineInventory` objects named `global-<system-uuid>`. |
| `SeedImage` | `global-registration-iso` | Builds the installation ISO from `tkestack/baremetal-base-image-iso:<isoImageTag>`. Its `COS_STATE` partition is sized to 20 GiB. |
| `elemental-image-catalog` entry | Kubernetes version | Maps the Kubernetes version to `tkestack/baremetal-base-image:<rootImageTag>`. `ac` writes the same entry on the `global` cluster in stage 8. |
| `Secret` | `dex.tls` | The certificate for the registration endpoint, issued for `global.bootstrapIP`. |
