# Overview of the global Cluster on Bare Metal

On Bare Metal, the `global` cluster runs on physical hosts that boot an installation ISO and register with the bootstrap cluster. The control plane endpoint is a Self-built VIP that the provider runs on the control plane nodes, or your load balancer. `ac adm alpha global create` runs twice: the first run builds the ISO and stops; you boot the hosts from it and assign them to pools; the second run installs the platform and hands the cluster over from the bootstrap cluster.

| Step | Page |
|---|---|
| 1. Prepare the OS images, the hosts, and the network | [Prerequisites](./prerequisites.mdx) |
| 2. Write `install-config.yaml`, build the ISO, register the hosts, create the pools, and install | [Create the global Cluster](./create_cluster.mdx) |
| 3. Optional: install a standby `global` cluster | [Disaster Recovery](../disaster_recovery.mdx) |
| When the installation does not advance | [Troubleshooting](./troubleshooting.mdx) |

`ac` does not delete a Bare Metal `global` cluster; see [Delete the global Cluster](./deleting.mdx). The fields of `install-config.yaml`, the rendered objects, and how Bare Metal DR works are in [Reference](./reference/index.mdx).
