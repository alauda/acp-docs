# Typical Installation Scenarios

Choose the deployment architecture in [Plan](../planning.mdx) first. Then read the scenario page of that architecture for its standard sizes, components, and installation steps on Alauda OS:

- [Single Cluster](./single_cluster.mdx): the `global` cluster also runs the application workloads.
- [Multi-Cluster](./multi_cluster.mdx): the `global` cluster runs only the platform, and application workloads run on workload clusters. It also covers an optional Ceph setup for workload clusters.

## Common Assumptions \{#common-assumptions}

- The scenarios apply to Bare Metal and to IaaS, which means Alauda OS on Huawei DCS, Huawei Cloud Stack, or VMware vSphere.
- The storage choices use the storage that <Term name="productShort" /> provides: TopoLVM, and Ceph through Alauda Storage.
- If enterprise storage is already available, it can hold all data except the node-local platform disks.
- Procedures, commands, and configuration fields are in the linked pages.
