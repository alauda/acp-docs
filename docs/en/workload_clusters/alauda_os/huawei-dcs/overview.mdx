# Huawei DCS Provider

The Infrastructure Provider for Huawei DCS clones each node from a DCS VM template. The VM template decides the Kubernetes version. The provider gives each node the fixed address and hostname that `install-config.yaml` lists for it.

- You reserve every node address in advance, because DCS does not reserve them.
- Disks declared as persistent, such as `/var/cpaas`, stay with the node's address slot and move to the replacement VM, so nodes are replaced one at a time.
- The control plane endpoint is an external load balancer or a Self-built VIP on the control plane nodes. `controlPlaneHA` keeps the control plane VMs on different DCS hosts with a DRS rule.
- The provider creates only the VMs and their volumes. The folder, switches, port groups, and datastores must exist on DCS beforehand.
- A DCS cluster is a pool of physical hosts, not the `DCSCluster` resource of one Kubernetes cluster. A datastore cluster is a group of datastores.
