# Delete a Cluster on Huawei DCS

:::warning
Deleting the cluster deletes the persistent and raw disks of every node, and their data cannot be recovered.
:::

```bash
ac adm alpha cluster destroy --dir <install-dir>      # preferred: manifests/ records what ac rendered
ac adm alpha cluster destroy --cluster <cluster-name> # without the directory
```

`destroy` lists what it will delete and asks you to type the cluster name; `--yes` skips the prompt and is required when standard input is not a terminal. It deletes the Cluster API `Cluster` first and waits for the machines to go, then removes the remaining objects that `ac` rendered. Deleting the `DCSIpHostnamePool` objects deletes their persistent and raw disks; `--reclaim-disks` is accepted and changes nothing. If `destroy` is interrupted, run it again; it resumes where it stopped.

`destroy` removes only objects that carry the cluster's ownership label. The credential Secret, a registry Secret, and the DCS folders, datastores, switches, and templates are left in place. `--cluster global` is refused.

If deletion stops on a machine, see [Troubleshoot a DCSMachine Stuck in Deleting](./troubleshooting.mdx#dcsmachine-stuck-deleting); if the `Cluster` stays in `Deleting`, see [Troubleshoot a Cluster Stuck in Deleting](../troubleshooting/troubleshoot-cluster-stuck-deleting.mdx).
