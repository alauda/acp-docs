# install-config.yaml Parameters for Bare Metal

This page lists the objects that `ac` renders from the `install-config.yaml` of a Bare Metal workload cluster. For the template and its fields, see [Write `install-config.yaml`](../create_cluster.mdx#write-install-config).

## Rendered Manifests \{#render-manifests}

`ac` writes the objects that it applies to `<install-dir>/manifests/`, one file for each object. All objects are in the `cpaas-system` namespace. For their API fields, see [API Reference](../../../../apis/kubernetes_apis/infrastructure_providers/bare-metal/index.mdx).

| Object | Name | Notes |
|---|---|---|
| `Secret` | `<cluster-name>-encryption-provider-config` | The encryption configuration, referenced by `BaremetalCluster`. |
| `Cluster` | `<cluster-name>` | Labeled `cluster-type: ProviderBaremetal`. The `cpaas.io/registry-address` annotation holds the registry address. |
| `BaremetalCluster` | `<cluster-name>` | `controlPlaneLoadBalancer` is set from `cluster.network.loadBalancer`, with the type written as `Internal` or `External`. |
| `BaremetalMachineTemplate`, `KubeadmControlPlane` | `<cluster-name>-control-plane` | The template references the control plane pool. With `3` or more replicas, the rollout strategy is `rolloutStrategy.rollingUpdate.maxSurge: 0`. A single replica gets no rollout strategy. |
| `BaremetalMachineTemplate`, `MachineDeployment` | `<cluster-name>-<group>` | The template references the group's pool. `maxSurge: 0`, `maxUnavailable: 1`. |
| `KubeadmConfigTemplate` | `<cluster-name>-<group>-config` | |

You manage the `MachineRegistration`, the `SeedImage`, and the pools yourself. `ac` does not render or delete them.

### Worker Objects \{#worker-machine-template}

The worker objects of the template in [Create a Cluster](../create_cluster.mdx#write-install-config) are rendered as follows. The `files` and `users` of the bootstrap template are abbreviated.

```yaml
apiVersion: infrastructure.cluster.x-k8s.io/v1beta1
kind: BaremetalMachineTemplate
metadata:
  name: <cluster-name>-worker
  namespace: cpaas-system
spec:
  template:
    spec:
      machineInventoryPoolRef:
        name: <cluster-name>-worker-pool
---
apiVersion: bootstrap.cluster.x-k8s.io/v1beta1
kind: KubeadmConfigTemplate
metadata:
  name: <cluster-name>-worker-config
  namespace: cpaas-system
spec:
  template:
    spec:
      joinConfiguration:
        nodeRegistration:
          kubeletExtraArgs:
            volume-plugin-dir: /opt/libexec/kubernetes/kubelet-plugins/volume/exec/
        patches:
          directory: /etc/kubernetes/patches
      postKubeadmCommands:
      - chmod 600 /var/lib/kubelet/config.yaml
      # files: the kubelet configuration patch; users: the boot user with cluster.sshKeys
---
apiVersion: cluster.x-k8s.io/v1beta1
kind: MachineDeployment
metadata:
  name: <cluster-name>-worker
  namespace: cpaas-system
spec:
  clusterName: <cluster-name>
  replicas: 3
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 0            # A pool cannot over-provision physical hosts
      maxUnavailable: 1
  template:
    spec:
      clusterName: <cluster-name>
      bootstrap:
        configRef:
          apiVersion: bootstrap.cluster.x-k8s.io/v1beta1
          kind: KubeadmConfigTemplate
          name: <cluster-name>-worker-config
      infrastructureRef:
        apiVersion: infrastructure.cluster.x-k8s.io/v1beta1
        kind: BaremetalMachineTemplate
        name: <cluster-name>-worker
      nodeDrainTimeout: 5m
      version: <kubernetes-version>
```
