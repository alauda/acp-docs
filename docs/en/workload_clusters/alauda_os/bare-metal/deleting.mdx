# Delete a Cluster on Bare Metal

Run the following command from a machine where `ac` is logged in to the platform:

```bash
ac config use-cluster global
ac adm alpha cluster destroy --dir <install-dir>      # preferred: manifests/ records what ac rendered
ac adm alpha cluster destroy --cluster <cluster-name> # without the directory
```

`destroy` lists what it will delete and asks you to type the cluster name; `--yes` skips the prompt and is required when standard input is not a terminal. The hosts are cleaned and released back to their pools. If it is interrupted, run it again; it resumes where it stopped.

`destroy` removes only objects that carry the cluster's ownership label. The `MachineRegistration`, the `SeedImage`, the pools, and the `MachineInventory` objects are left in place for the next cluster. `--reclaim-disks` is rejected on Bare Metal, and `--cluster global` is refused.

If the `Cluster` stays in `Deleting`, see [Troubleshoot a Cluster Stuck in Deleting](../troubleshooting/troubleshoot-cluster-stuck-deleting.mdx).
