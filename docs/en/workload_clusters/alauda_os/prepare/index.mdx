# Prepare

Complete the following preparation before you create a workload cluster on Alauda OS. It applies to every provider. For the list of supported providers, see [Supported Providers](../index.mdx#supported-providers).

## Install the Infrastructure Provider \{#install-the-provider}

After the `global` cluster is installed, and before you create a workload cluster on Bare Metal, Huawei DCS, Huawei Cloud Stack, or VMware vSphere, upload and install the infrastructure provider for that IaaS platform on the `global` cluster. This applies regardless of which IaaS platform the `global` cluster itself runs on.

In addition to the infrastructure provider, the following component is required for every provider:

- **Alauda Container Platform Cluster Bootstrap Provider**: Handles Kubernetes bootstrap and control plane management

Install both as follows:

1. **Download**: Download the packages from the Customer Portal. For <Term name="productShort" /> 4.5, the providers are listed under **Common ACP Extensions**. See [Download Packages](../../../extend/download_package.mdx).
2. **Upload**: Upload the packages to the platform with `violet push`. See [Upload Packages](../../../extend/upload_package.mdx#violet_push_usage).
3. **Install**: Install the packages as cluster plugins on the `global` cluster. See [Cluster Plugin](../../../extend/cluster_plugin.mdx).

For the packages and verification steps of each provider, see:

- [Bare Metal](../bare-metal/install_provider.mdx)
- [Huawei DCS](../huawei-dcs/install_provider.mdx)
- [Huawei Cloud Stack](../huawei-cloud-stack/install_provider.mdx)
- [VMware vSphere](../vmware-vsphere/install_provider.mdx)

## Configure Infrastructure Resources \{#infrastructure-resources}

Before creating clusters, configure the infrastructure resources that the provider requires:

- **Cloud Credentials**: Store IaaS platform access information
- **IP Pools**: Define network configurations for cluster nodes
- **Machine Templates**: Specify virtual machine specifications
- **Network Inventory and Load Balancer Plans**: Prepare subnet inventories and API server access addresses when the provider requires them

| Provider | Description |
|----------|-------------|
| [Huawei DCS](../huawei-dcs/infrastructure.mdx) | Huawei Datacenter Virtualization Solution |
| [Huawei Cloud Stack](../huawei-cloud-stack/infrastructure.mdx) | Huawei Cloud Stack |
| [VMware vSphere](../vmware-vsphere/infrastructure.mdx) | vCenter inventory, credentials, network, template, endpoint, and storage preparation |

Bare Metal has no separate infrastructure resource page. Its host preparation is part of [Install the Bare Metal Provider](../bare-metal/install_provider.mdx) and [Create a Cluster on Bare Metal](../bare-metal/create_cluster.mdx).

## Plan the Control Plane Endpoint \{#control-plane-endpoint}

Every cluster needs a stable endpoint for the Kubernetes API, and the endpoint mode must be selected before the cluster is created. See [Plan the Control Plane Endpoint](./control-plane-endpoint.mdx).

## Choose the Image Registry \{#image-registry}

By default, a workload cluster uses the image registry of the `global` cluster. A cluster can instead be bound to a dedicated registry, but only when it is created. See [Choose the Image Registry for a Workload Cluster](./workload-cluster-image-registry.mdx).
