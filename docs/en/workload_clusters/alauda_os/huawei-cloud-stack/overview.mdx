# Huawei Cloud Stack Provider

<Overview />

The Infrastructure Provider for Huawei Cloud Stack (HCS) creates the ECS instances, the EVS disks, and the control plane Elastic Load Balance (ELB) of each cluster in an existing VPC, subnet, and security group. You reserve a static IPv4 address for every node and the ELB addresses in advance; you do not prepare a load balancer. Persistent disks such as `/var/cpaas` are EVS disks bound to the node's entry in its pool and move to the replacement instance, so nodes are replaced one at a time. Each node group runs in one availability zone; use several worker node groups to spread workers across zones. The control plane is spread across hosts with an HCS server group by default. `ac` does not look up the HCS objects that `install-config.yaml` names, so a wrong name fails only when the provider creates the instances.

Create HCS clusters with ACP CLI (ac) from one `install-config.yaml`; see [Create a Cluster on Huawei Cloud Stack](./create_cluster.mdx). For day-2 node operations, see [Manage Nodes on Huawei Cloud Stack](../../../configure/nodes/alauda_os/huawei-cloud-stack.mdx).
