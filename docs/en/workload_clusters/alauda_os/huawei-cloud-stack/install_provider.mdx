# Install the Huawei Cloud Stack Provider

This document describes how to install the Infrastructure Provider for Huawei Cloud Stack and the Cluster Bootstrap Provider on the `global` cluster.

## When You Need This

Complete this page after the `global` cluster is installed and before you create the first workload cluster on Huawei Cloud Stack. It is required regardless of the IaaS platform that the `global` cluster itself runs on.

This is a separate task from the provider steps in [Installing the global Cluster](../../../install/alauda_os/installing.mdx). Those steps upload provider packages to the temporary bootstrap cluster to create the `global` cluster itself.

## Prerequisites

Before installing the provider, ensure you have:

- Access to the <Term name="product" textCase="capitalize" /> `global` cluster
- Access to Customer Portal for downloading plugins

## Steps

<Steps>
### Download the packages

To create clusters on Huawei Cloud Stack, you need two cluster plugins. Download both from the Customer Portal. For <Term name="productShort" /> 4.5, they are listed under **Common ACP Extensions**; see [Download](../../../install/prepare/download.mdx).

1. **Alauda Container Platform Cluster Bootstrap Provider**
2. **Alauda Container Platform Infrastructure Provider for Huawei Cloud Stack**

### Upload the packages

Upload both packages to the platform with `violet push`. For the command and its parameters, refer to [Upload Packages](../../../extend/upload_package.mdx#violet_push_usage).

### Install the cluster plugins

Install both cluster plugins on the `global` cluster. For the procedure, refer to [Cluster Plugin](../../../extend/cluster_plugin.mdx).

### Verify the installation \{#verify-the-installation}

After installing the provider, verify that it is correctly installed:

```bash
# Check if the HCS provider pods are running
kubectl get pods -n cpaas-system | grep hcs

# Verify HCS CRDs are registered
kubectl get crd | grep -E '^hcs.*\.infrastructure\.cluster\.x-k8s\.io$'

# Expected output should include:
# hcsclusters.infrastructure.cluster.x-k8s.io
# hcsmachines.infrastructure.cluster.x-k8s.io
# hcsmachinetemplates.infrastructure.cluster.x-k8s.io
# hcsmachineconfigpools.infrastructure.cluster.x-k8s.io
```

</Steps>
