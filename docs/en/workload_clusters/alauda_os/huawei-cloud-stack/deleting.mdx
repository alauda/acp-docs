# Delete a Cluster on Huawei Cloud Stack \{#delete-with-ac}

:::warning
Deleting the cluster deletes the persistent and raw EVS disks of every node, and their data cannot be recovered.
:::

Run one of the following commands from a machine where `ac` is logged in to the platform:

```bash
ac config use-cluster global
ac adm alpha cluster destroy --dir <install-dir>      # preferred: manifests/ records what ac rendered
ac adm alpha cluster destroy --cluster <cluster-name> # without the directory
```

`destroy` lists what it will delete and asks you to type the cluster name; `--yes` skips the prompt and is required when standard input is not a terminal. If `destroy` is interrupted, run it again; it resumes where it stopped.

`destroy` removes only objects that carry the cluster's ownership label, including the encryption Secret that `ac` rendered. The credential Secret, a registry Secret, and the HCS VPC, subnets, security group, and image are left in place. `--cluster global` is refused.

If the `Cluster` stays in `Deleting`, see [Troubleshoot a Cluster Stuck in Deleting](../troubleshooting/troubleshoot-cluster-stuck-deleting.mdx).
