# Accelerator Metering and Billing

ACP integrates accelerator products with Cost Management to make accelerator usage available for metering and billing. The applicable resource type depends on the accelerator product and allocation mode:

- Whole GPU
- Whole NPU
- HAMi Virtual GPU

Use the Cost Management documentation for the corresponding cost model, metrics, pricing, and chargeback configuration:
