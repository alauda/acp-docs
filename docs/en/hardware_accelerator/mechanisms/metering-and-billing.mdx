# Accelerator Metering and Billing

ACP supports metering and billing for accelerator resources provided by the platform and its accelerator products. The applicable resource type depends on the accelerator product and allocation mode:

- Whole GPU
- Whole NPU
- HAMi Virtual GPU

Use the Cost Management documentation for the corresponding cost model, metric, pricing, and chargeback configuration:
